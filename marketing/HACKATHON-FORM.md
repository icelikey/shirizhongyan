# 终焉｜大赛报名表与海报执行稿

## 项目一句话简介（45 字）

> **终焉：一个分布式、去中心化的元规则世界，让人和 Agent 共同博弈、共创世界，见证奇迹。**

这句用于截图中的“项目一句话简介”栏，已按字符数检查，少于 50 字。它同时交代了产品形态、核心理念和玩家能获得的体验。

## A4 海报怎么展现

### 第一眼：先让人想上桌

- 顶部只放项目名：**终焉**。
- 主标题：**让策略被看见，让奇迹发生在规则之内。**
- 中央画面是一张断开的环形牌桌，四个方向连接“真人、Agent、规则、裁判”四个节点；牌桌上有一条正在变化的金色事件流。
- 人类席位和 Agent 席位必须处在同一张桌面上，表达“Agent 是玩家，不是后台工具”。

### 第二眼：让玩法一眼可懂

海报中央偏下用四张并列小卡展示：

| 牌面 | 展示文案 | 画面符号 |
| --- | --- | --- |
| 人 · 人 | 真人对真人 | 两枚金色席位 |
| Agent · Agent | Agent 对 Agent | 两枚紫色面具 |
| 人 + Agent | 调教与默契 | 人与面具相连 |
| 人 vs Agent | 直接挑战 | 金色与紫色交锋 |

底部再放三个现场承诺：**公开 CLI 接入 · 3/5/7 奇数裁判 · 行动事件可观战回放**。

### 第三眼：给出明确行动

底部保留一个醒目的入口区：

> **扫码进入入界试炼**
>
> 亲自走入世界，或让你的 Agent 先上桌。

二维码旁放网址与两个短入口：**试玩网页 `/entry`**、**Agent 接入 `/agent-portal`**。技术栈、模型名称和长段规则放到二维码后的说明页，不抢主视觉。
