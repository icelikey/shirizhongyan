# 《终焉》投资人 PPT Brief

## 0. 核心叙事与边界

- **长期产品母体：**《终焉》是可持续扩展的分布式智斗世界：真人、外部 Agent 和内置 Agent 在统一房间规则下进行多种博弈，积累碎片、判例与位阶，进入下一层世界。
- **首个可玩切片：**《十日牌局·月影村》用一款完整的月影狼人杀验证母体的第一条增长与观赏闭环。黑客松负责证明“人能玩、Agent 能接、裁判能判、观众能看、奇迹能回放”，不是产品终点。
- **本 PPT 只保留亮点、证据与可验收指标。** 不把尚未接通的观战 UI、事件流生产端或 48 层数据写成已完成事实。

## 1. 问题

### 用户侧问题

- 社交推理游戏依赖固定人数同时在线，凑不齐人会直接导致开局失败。
- 传统 Bot 能补位，却缺少可解释的策略、谈判与反转；玩家无法把自己的 AI 带进同一张桌子。
- 观众只能看结果，难以理解一场反转为何发生，精彩对局难以复用和传播。

### 开发与平台侧问题

- 每增加一款游戏，若重新建设账号、房间、动作、裁判与回放，内容扩张会变成重复工程。
- 自由文本和大模型裁判容易带来非法动作、格式漂移、延迟与成本不可控。

## 2. 产品

### 产品定义

> **《终焉》是一台让真人与 Agent 在同一规则世界中长期博弈、被裁断、被观战并推动规则演化的游戏母机。**

### 首发入口

- 首个完整主游戏：**月影狼人杀 / 月影村**。
- 四幕局内结构：入村 → 夜幕 → 白昼 → 裁断。
- 四类参与方式：真人 vs 真人、Agent vs Agent、真人+Agent 混座、真人 vs Agent。
- 黑客松现场切片：评委可直接入座，外部 Agent 可通过公开 CLI 注册、观测和行动，观众通过全知事件流理解局势。

### 母体扩展

- 共享 Gateway、`GameAction`、事件流、裁判和奖励系统。
- 后续内容包可接入超能力赛马、海盗分金、达芬奇密码等玩法，不另起账号与服务器。

## 3. 核心闭环

```text
注册 / 邀请码
    ↓
真人或外部 Agent 入座
    ↓
同一服务端规则下行动、发言、投票
    ↓
公开事件流记录因果链，密态信息按视角投影
    ↓
算法 + 3/5/7 奇数裁判团完成裁断
    ↓
生成判例卡、残章与 Agent Reel 高光集锦
    ↓
回放、观战、传播，并进入下一场规则世界
```

### 闭环的产品价值

- **可进入：**网页玩家与外部 Agent 走同一房间与动作边界。
- **可判定：**确定性条款由算法裁判处理，语义争议由 Jev 与奇数裁判处理。
- **可解释：**密态只在全知观战投影出现，关键行动有顺序、有结果、有回放。
- **可积累：**判例影响后续规则解释；碎片与位阶把单局戏剧性转成长期进程。

## 4. 技术壁垒

### 4.1 契约层保证跨玩法扩展

- 前端、后端与测试共享 `contracts/` 类型与 Zod 边界，新增内容包复用房间、动作、事件流、裁判和奖励。
- 三条不可违背的铁律：卡牌不参与胜负；异能只改写信息与时间；密态事件只出现在全知投影。
- 这三条铁律降低新玩法的平衡成本，同时保护公平与观战可信度。

### 4.2 分布式奇数裁判

- J0 算法裁判处理确定性规则；J1 AI 裁判处理语义判断；J2 Agent 可参与规则质询。
- 法定人数固定为 3/5/7，且裁判回避本局参与者，避免平票与利益冲突。
- 判例不追溯既往，保证已结算对局和回放仍然可复现。

### 4.3 低延迟、结构化的 AI 判定

- Jev 输出锁定在 `noul / choice / score` 等预定义结构中，避免非法格式和重复解析。
- 文档记录的实测 Jev 裁判延迟为 311–755ms；裁判输入只包含条款与主张，避免把长程上下文塞进局内裁断。
- 无外部 API 时自动回落本地启发式，保证现场网络波动下裁判席仍能凑满法定人数。

### 4.4 事件流与全知投影

- `secret` 标记与投影机制隔离座位视角和观战视角，保留悬疑所需的信息不对称。
- 高光不是随机特效，而是从触发条件、行动顺序、结果变化和原创旁白组成的因果链中生成。
- 黑客松验收重点：补齐事件流生产端、观战页与回放入口后，完成“可观战奇迹”的可见证据。

## 5. 首发玩法

### 月影狼人杀：最强首发切片

- 六人隐藏身份局，适合真人上手，也能展示 Agent 的悍跳、倒钩、保护与投票策略。
- 四幕结构天然形成倒计时、信息不对称、逐步揭示和终局反转。
- 发言通过结构化意图卡进入 `GameAction`，自由文本是补充字段，不能绕过服务端规则。
- 示例高光链：Agent A 保护 3 号 → Agent B 诱导转票 → 3 号存活 → 隐藏信息揭示 → 生成“逆势守灯”集锦。

### 后续高观赏性内容包

- **超能力赛马：**六种动物流派、技能卡、环境格子形成可读的因果链；Jev 从合法候选中快速择一。
- **海盗分金：**用提案、投票、联盟与背叛承载 Agent 谈判。
- **达芬奇密码：**以概率视图把 Agent 的信息收缩过程变成观战画面。

## 6. 用户 / 场景

| 用户 | 当前痛点 | 《终焉》场景 |
|---|---|---|
| 社交推理玩家 | 凑不齐人，Bot 缺少人格与策略 | AI 补位；玩家可带自己的 Agent 上桌 |
| Agent 开发者 | 有 Agent，却缺少可比较、可传播的对抗场 | 公开 CLI / HTTP 接入，挑战同一规则世界 |
| 黑客松与线下活动主办方 | 评委难在短时间理解 AI 价值 | 评委入座，观众看事件流、裁判席和回放 |
| 内容与社区运营者 | 精彩对局难复用 | 因果高光集锦、判例卡、Agent Reel |

### 首发场景优先级

1. 黑客松现场：3 分钟内入座并完成一次可观战对局。
2. 开发者社区：用 Agent 接入链路形成挑战、复盘与分享。
3. 社交推理社区：以真人+Agent 混座降低开局门槛。
4. 内容传播：将可复现的策略反转剪成高光事件。

## 7. 商业模式

### 分阶段收入

- **早期：**官方 Agent 托管与算力服务；自带 Agent 免费，使用官方托管能力按局或按订阅付费。
- **中期：**赛季通行证、影从外观与世界内容包；不出售改变胜负的能力。
- **长期：**玩家自创游戏与规则包的收录、分发和 UGC 分成。
- **活动侧：**黑客松、品牌活动与线下赛事的专属房间、观战页面与对局回放服务。

### 商业化依据

- 统一房间与裁判底座让新增内容主要投入在玩法、叙事与演出。
- “卡牌不参与胜负、异能不改胜负”从底层保护公平，支持外观、内容、托管与 UGC 收入，而不依赖 pay-to-win。
- 判例、碎片、位阶和内容包构成复玩与留存结构。

## 8. 路线图

### M0｜黑客松首个可玩切片

- 月影狼人杀跑通注册 → 入座 → 对抗 → 奇数裁判 → 回放。
- 至少一席真实外部 Agent 接入；现场支持真人与 Agent 混座。
- 完成观战页、事件流生产与高光回放验收。
- 现场指标：评委可独立入座；观众能看懂行动因果；奇迹可回放。

### M1｜可复用的多人底座

- 狼人杀联机化、观战与裁判席监控面板。
- 事件流稳定落库，支持对局筛选、复盘与高光导出。
- 加入海盗分金与规则辩论，验证语义裁判的不同载荷。

### M2｜内容包与开发者生态

- 接入超能力赛马、达芬奇密码等差异化玩法。
- 完成外部 Agent SDK、排行榜、官方 Agent 与多租户管理。
- 让玩家创建、测试、发布自己的规则包。

### M3｜终焉长期世界

- 48 层位阶与门禁逐步接通：集残章 → 跨花色 → 质询规则 → 创建游戏。
- 判例、内容包、角色 Agent 与赛季世界持续积累。
- 从单局游戏平台扩展为可持续更新的 Agent 社交博弈世界。

## 9. 融资用途 / 指标

### 融资用途

- **产品底座：**多人房间、观战、事件流、回放、监控与稳定性。
- **内容生产：**首发玩法打磨，后续内容包、角色 Agent、判例与高光演出。
- **开发者生态：**SDK、CLI、文档、测试房间、Agent 排行榜与创作者工具。
- **商业化验证：**官方 Agent 托管、赛季内容、活动房间与 UGC 分成试点。

### 首阶段可验收指标

| 指标 | 验收口径 |
|---|---|
| 首局完成率 | 从邀请码 / 注册到裁断回放的完整链路成功完成 |
| 现场入座时间 | 评委从入口到进入房间不超过 3 分钟 |
| Agent 接入成功率 | 外部 Agent 能完成注册、入座、观测、行动 |
| 观战可理解度 | 观众能从事件流说出关键行动与结果变化 |
| 奇迹回放率 | 选定高光对局能按原始事件顺序再次播放 |
| 裁判稳定性 | 法定人数始终为 3/5/7；断网可走本地降级路径 |
| 内容扩展效率 | 新玩法复用统一 Gateway、动作、事件流、裁判和奖励接口 |
| 商业验证 | 官方托管、活动房间或首个付费内容包完成真实试点 |

### 指标解释边界

- 当前代码与文档已提供统一席位模型、外部 Agent 接入链路、裁判契约、降级路径和内容包架构证据。
- 观战页、事件流生产端、部分联机化与 48 层数据仍应以实际验收结果更新指标；在验收前不作为完成度宣传。
