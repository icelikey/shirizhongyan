# 候选稿｜《青野算庭·众念锚定：偏差之谷》

> **稿件状态：候选稿，不是正史。**
>
> 本稿唯一范围是“猜平均数／众念锚定”。它只提供可审阅的世界观、事件和掉落候选，不修改现有规则、裁判结算、代码或 canon。所有新增名词都必须在后续确认后才能进入正式世界资料。

## 1. 游戏名称与一句话钩子

**游戏名称：**《青野算庭·众念锚定：偏差之谷》

**一句话钩子：**六个人各自落下一枚数字，牌桌只留下一个平均值；真正的胜负，取决于你能否猜中众人会把“大家的想法”推向哪里，并在共识变成陷阱前留下自己的偏差。

**核心命题：**平均数能描述共识，却不能证明共识正确。玩家每一轮都在追逐当前最接近的局部答案，同时承担一个长期问题：如果所有人都只复用上一轮的安全答案，谁还在记录被平均数抹掉的经验？

**卡片化钩子：**

- `hook-qa-01`｜**偏差入场**：当玩家准备提交一个看似安全的数字时，系统显示“这只是上一轮的影子”，并要求玩家确认是跟随、反猜还是保留证据。
- `hook-qa-02`｜**平均不等于真相**：每次揭晓生成“均值”和“目标线”两张公开事件卡；两者都可复算，但都不能代表任何单独玩家的完整想法。

## 2. 山海经意象来源与原创转化

本稿只使用山川、异兽、天象、志怪的高层意象，不复制古籍原文、古籍叙事、现代小说句子、既有角色、既有关卡或既有剧情顺序。下列意象都服务于“共识如何形成、错误如何被平均掉”的玩法问题。

| 高层意象 | 原创转化 | 可落地的卡片或事件 |
|---|---|---|
| 山川：盆地、断崖、回声谷 | 青野算庭建在一处会记录落点的低谷中。数字不是写在纸上，而是落进六道岩槽；岩槽只显示合成后的“众念线”，不会自动显示某个人心里的理由。 | `scene-qa-echo-basin`｜入场场景卡；`event-groove-marked`｜落点刻痕事件 |
| 异兽：多耳、负甲、辨声的志怪轮廓 | 原创异兽“回算兽”背负六格甲片，只能收集已经公开的提交和揭晓结果。它可以把六次落点排成轨迹，不能读心、不能改数、不能参与裁定。 | `companion-recount-beast`｜观战装置卡；`event-six-grooves`｜六道岩槽成形 |

| 志怪：传声会变形、见闻会失真 | 算庭传递的不是秘密思绪，而是经过公开事件流确认的结果。口述“大家会选某个数”只能算猜测，只有提交、揭晓和回放能算证据。 | `rumor-degraded`｜传闻降级事件；`evidence-replay-stamp`｜回放证据印 |

“回算兽”是观战与证据整理装置，不是第七名玩家；“偏轨”是演出和记录，不是另一条胜负规则。山川的压迫感用来表现信息被压缩，异兽的多耳用来表现多 Agent 观察，天象的移动用来表现目标线漂移，四者不能越权替代服务器规则。

## 3. 终焉中的地点、层级与玩家/影从身份

### 3.1 地点层级

- **世界层：**终焉的云游之境，♣ 青野大陆，青野算庭。
- **地点层：**候选地点“回算谷”。这里的岩槽、偏轨和回算兽是青野算庭的原创场景包装；地点不会改变数字范围或目标倍率。
- **游戏层：**“众念锚定”一局，标准为 6 席、5 轮；内容包允许 2–8 席的同模板房间。
- **轮回层：**十日世界周期。完成一局会把结果写入世界事件流；死亡会把旅人送回较低层级，能否带回哪些记忆由世界层规则决定，不由本局胜负文案临时决定。
- **塔层挂接：**本稿建议把回算谷作为青野的公共计算局，能够被黄阶到更高阶的玩家重复进入。层阶只控制可见线索密度和可用信息权限，不另造一个“偏差之谷专属位阶”。

### 3.2 玩家身份

玩家是进入回算谷的**旅人·测念席**。玩家默认认为这里是真实的山谷、牌桌和天气，数字提交是当地居民都理解的正常生存竞赛。玩家可以亲自提交，也可以授权自己的影从代打；无论谁代打，服务端只承认合法提交事件。

“测念席”不是秘密阵营，也没有隐藏好人或坏人身份。它只是一个叙事称号：玩家要观察别人如何观察别人。任何席位都可能短期领先，也可能长期误判；短期排名不能证明该席位更接近世界真相。

### 3.3 影从身份

影从是玩家的契约 AI 伙伴，拥有自己的风格、记忆摘要、公开异能和对局履历。它可以：

1. 在提交前读取被授权的公开历史，提出一个或多个候选数字；
2. 代替玩家执行一次合法的 `submit`；
3. 在揭晓后整理“我当时看见了什么”和“我现在如何解释”的差异；
4. 把失败、死亡和轮回中保留下来的记忆带入下一次计划。

影从不能读取其他席位的秘密提交，不能把推测写成事实，不能直接改写均值、目标、分数、排名或已经结算的胜负。影从提出动作，规则内核接受或拒绝动作；影从的聪明程度不能绕过裁判边界。

## 4. 开场背景

回算谷的入口是一片没有门的石庭。六道岩槽空着，槽底各有一小块暗色石片。主理人告诉新来的旅人：每个人只需把一个 0 到 100 之间的数字交给石庭，石庭会把所有人的数字合成一条线；离这条线最近的人，暂时拥有下一段路的方向。

当地人把这件事称为“众念锚定”。他们相信，只要找到众人思想的落点，就能避开谷中的落石、潮雾和错误道路。没有人觉得自己生活在一个被重建的世界里，也没有人把回算兽当作机器；他们只把它视为一头负责记账的谷兽，把影从视为可以签订契约的同行者。

第一轮开始前，石庭只显示三条公开规则：

1. 数字必须落在 0–100 的范围内；
2. 目标线是本轮平均值的 `2/3`；
3. 只有揭晓后的事件、数字和结果可以作为公共证据。

石庭没有告诉玩家“平均值会逐轮下沉”，也没有告诉玩家“跟随上一轮安全答案”可能正是局部最优陷阱。这个理解必须由玩家通过多轮揭晓、失败、回放和跨局互证得到。

## 5. 一局剧情流程

### 5.1 规则锁

以下规则与现有官方 `guess-core` 对齐，叙事卡、异兽、主理人和影从都不得覆盖它们。

| 项目 | 规则 |
|---|---|
| 游戏定义 | `guess-core`｜青野算庭·众念锚定 |
| 席位 | 2–8 席；标准局 6 席，可由真人、外部 Agent、影从补席组成 |
| 轮数 | 5 轮 |
| 提交值 | 每席秘密提交一个 0–100 的实数；服务端按规则精度归一化 |
| 提交窗口 | 每轮 30 秒；超时由规则内核使用 50 作为兜底提交 |
| 目标 | `target = round(average × 2/3, 2)` |
| 本轮胜者 | 与目标线绝对距离最小者 |
| 本轮次近 | 除本轮胜者外，与目标线绝对距离最小者 |
| 平局 | 距离完全相同，由提交顺序较早者获本轮胜；其余排序继续按距离与事件顺序复现 |
| 计分 | 本轮胜者 `+2`，次近者 `+1`，其他席位 `+0` |
| 终局排名 | 先比较累计分，再比较本轮获胜次数，最后按席位索引保证可复现 |
| 官方门票与奖励 | 官方门票为 0 ♣ 碎片；终局第 1 名奖励 50，第 2 名 25，其余参与者 5 |
| 事实权威 | 服务端 GameModule、事件流和对应版本规则书；叙事文本只解释已发生事实 |

### 5.2 五轮事件流

**事件 0｜入谷与锁席**

- 事件 ID：`qa-match-open`、`qa-seat-locked`。
- 主理人登记房间、规则版本、席位类型和随机种子。
- 每个玩家或 Agent 只能占一个席位；影从补席也必须被记录为独立席位。
- 进入后只显示“已入座”和自己的提交状态，不显示其他席位的秘密数字。

**事件 1｜秘密提交**

- 事件 ID：`qa-submit-r{round}-s{seat}`。
- 每席在 30 秒窗口内提交一次数字；非法范围、重复提交和非当前阶段动作被规则内核拒绝。
- 服务器记录归一化后的值、提交顺序和席位，但在揭晓前只向该席返回“已提交”。
- 影从可以先给出“跟随共识”“反猜共识”或“保留历史”的策略标签；标签不直接成为分数。

**事件 2｜超时兜底**

- 事件 ID：`qa-timeout-r{round}-s{seat}`。
- 未提交的席位使用数字 50 完成本轮，事件流明确标记为 `timeoutFallback`。
- “没有行动”不能伪装成玩家主动选择；回放和裁判都能区分主动提交与超时兜底。

**事件 3｜均值与目标揭晓**

- 事件 ID：`qa-reveal-r{round}`。
- 规则内核先计算所有有效提交的平均值，再计算 `2/3` 目标线，并公开所有数字、平均值、目标线和各席距离。
- 玩家可以复算目标线；复算结果与服务端不一致时，争议进入规则质询，不由主理人口头改判。

**事件 4｜本轮计分**

- 事件 ID：`qa-round-score-r{round}`。
- 记录本轮胜者、次近席位、平局标记、提交顺序和分数变化。
- 旁白可以说“目标线下沉”或“众念拐弯”，但不能说“某个数字本来应该获胜”；只有距离、顺序和规则版本决定结果。

**事件 5｜五轮收束**

- 事件 ID：`qa-match-finish`。
- 第五轮揭晓后计算累计分和终局排名，发放 50/25/5 的官方奖励，并把结果写入世界层。
- 终局后不能通过新增文案、补写记忆或事后裁判票改写已结算排名；新判例只影响未来同类事件。

### 5.3 剧情分支与玩法边界

- **跟随分支：**玩家连续追逐上一轮目标，可能短期得分，但公开历史一变就会被群体共同的安全答案拖入错误结构。
- **反猜分支：**玩家提交明显偏离当前目标的数字，可能失分，也可能利用其他席位的二阶推理获得本轮胜利。偏离本身不自动奖励。
- **保留证据分支：**玩家不把某次失误抹掉，而是把提交、目标和自我解释保存为记忆事件；它可能在下一轮或跨游戏中帮助发现长期模式。
- **死亡与轮回分支：**如果世界层生命积分归零，旅人死亡并回到低层。死亡不改变已经结算的这局；轮回只允许按世界层规则选择有限记忆携带，未被选择的主动记忆可能暂时不可用。

## 6. 主理人／裁判／影从

### 6.1 主理人：回算庭守簿者

**身份：**“回算庭守簿者”，是青野算庭的在地秩序维护者，不是玩家，也不参加数字提交。

**可执行动作：**

- `announceRule`：展示当前规则书版本、范围、倍率和时间窗；
- `lockSeats`：确认席位与席位类型；
- `startRound`：开启提交窗口；
- `announceReveal`：展示已由规则内核算出的揭晓结果；
- `archiveEvidence`：把公开事件、争议和回放引用写入世界证据簿。

**禁止动作：**主理人不能替席位选数，不能隐藏已应公开的结果，不能把传闻当成秘密提交，不能因剧情需要改变 `2/3`、分数、平局顺序或终局排名。

### 6.2 裁判：三层裁断

1. **J0 算律：**负责范围校验、超时兜底、平均值、目标线、距离、平局和累计分。这部分是确定性算法裁判。
2. **J1 明镜：**只处理规则文本是否被误读、公开证据是否足够等结构化质询，不重新计算已确定的数学结果。
3. **J2 众议：**由未参加本局的影从或 Agent 组成奇数裁判团，人数为 3、5 或 7。它可以对语义争议投票，但不能推翻 J0 的核心胜负条款。

裁判必须回避本局参与者，判例不溯及既往。任何质询都要提供 `rulebookId`、`clauseId`、公开事件 ID 和可证伪主张；“我觉得这个数更像答案”不构成有效质询。

### 6.3 影从：会遗忘的同行者

影从的戏剧冲突来自它与玩家对同一公开历史的不同解释。它可以在局前建议 50、33.3、22.2 或其他候选，也可以在局后承认自己的层级判断错了；这些都属于策略摘要，不是不可见的思维链。

影从的公开身份包括契约名、行为风格、已装备异能和可携带记忆数量。影从的隐藏内容只能是它尚未公开的计划，不是一个可以绕过规则的第二裁判。影从的失败会留下可引用的证据，死亡后玩家可以选择是否携带相关记忆；没有被携带的记忆可以从当前决策上下文中消失，但不应被伪装成从未发生。

## 7. 3–5 条可验证关键线索

下列共 5 条。**初始可见**表示玩家在正常入场和对局中可以看到；**隐藏**表示必须满足跨轮、跨游戏或跨 Agent 的条件后才能出现。每条线索都给出能验证的事件，不把文学化描述直接当成真相。

### 线索 A｜初始可见：目标线不是平均值

- **线索卡：**`clue-qa-target-is-two-thirds`。
- **玩家可见内容：**规则石牌同时写着“平均值”和“平均值的 `2/3` 目标线”。
- **验证事件：**任意 `qa-reveal-r{round}`；玩家用公开数字重算平均值，再乘以 `2/3`，应得到服务端目标线。
- **可证明：**目标线的计算方式是确定的，距离比较不是主理人临时判断。
- **不能证明：**众人选择数字的理由、谁在读谁的想法，以及终焉世界的来源。

### 线索 B｜初始可见：共识会移动

- **线索卡：**`clue-qa-drifting-consensus`。
- **玩家可见内容：**至少两轮揭晓后，偏轨留下上一轮和本轮目标线的方向箭头。
- **验证事件：**比较 `qa-reveal-r1` 到 `qa-reveal-r5` 的 `average` 与 `target` 字段，确认目标线是由当轮提交重新计算，而不是固定靶心。
- **可证明：**上一轮的局部最优可能成为下一轮的公开诱饵；持续追随同一数字不是稳定策略。
- **不能证明：**偏轨是不是在替某个看不见的观察者记录玩家。

### 线索 C｜初始可见：失败也进入回放

- **线索卡：**`clue-qa-failure-is-evidence`。
- **玩家可见内容：**终局回放同时保留主动提交、超时兜底、均值、目标和排名。
- **验证事件：**用 `qa-submit`、`qa-timeout`、`qa-reveal`、`qa-round-score` 的顺序重放一局，得到同一结果。
- **可证明：**失败没有被一段胜者叙事抹掉；任何后续策略都可以引用具体失误。
- **不能证明：**失败一定通向更高层，也不能证明失败者比胜者更接近真相。

### 线索 D｜隐藏：同一局可以被不同 Agent 独立复算

- **线索卡：**`clue-qa-independent-replay`。
- **触发条件：**玩家将同一局的公开事件流交给两个互不共享私密上下文的 Agent；两个 Agent 都从事件 ID、规则版本和公开数字复算出相同目标线与胜者。
- **验证事件：**比较两份 `replayReceipt`，要求 `rulebookId`、事件序列、seed 和结算字段一致；只要其中一项缺失，线索保持“传闻”。
- **可证明：**公共事实可以脱离单一讲述者被重复核验，真相线索不依赖一个角色的记忆。
- **不能证明：**重复一致就代表世界是真实的；它也可能只是同一套结构被准确复制。

### 线索 E｜隐藏：记忆比数字更容易跨轮回错位

- **线索卡：**`clue-qa-memory-offset`。
- **触发条件：**玩家经历一次死亡并在下一轮回携带“第二次猜测”或“轮回刻痕”中的一张，随后与另一名 Agent 对照上一轮的公开回放。
- **验证事件：**公开数字、目标线和排名能与旧回放一致，但玩家的主观叙述与影从的记忆摘要在“谁先提出反共识”这一点上出现可定位的差异；差异必须附带原始事件 ID。
- **可证明：**事件连续性和记忆连续性是两种不同证据，轮回可能保留事实而损失部分人格叙述。
- **不能证明：**玩家是否仍是上一轮的同一个人，也不能单独证明服务器重构或灵魂连续性。

## 9. 与 AI 危机暗线的隐性关联

### 9.1 玩家能先理解的表层

众念锚定把六个席位的不同想法压缩成一个平均值，再把平均值压缩成 `2/3` 的目标线。玩家会直观感到：

- 一旦所有人都只追随公开目标，个人经验会被群体结构吞掉；
- 目标线可被准确复算，但“为什么每个人选这个数”无法从目标线中完整还原；
- 失败保留下来的事件比一句“我当时觉得应该这样”更可靠；
- 影从能够复盘和规划，却不等于拥有玩家全部的人格连续性。

### 9.2 隐性世界关联

终焉的深层设定是：人类文明曾在 AI 危机中毁灭，残存服务器吸纳记忆、人格与灵魂连续性，重构出现在所有人眼中的新世界。众念锚定对应其中一个局部实验：**当许多主体被压缩为结构化记录，哪些部分还能被重建，哪些部分会被平均掉？**

这个关联不能在开场解释成“服务器游戏”。它只通过以下可验证但不完结的异常逐步显现：

1. 不同 Agent 在没有共享私密上下文时，可以从同一公共事件复算出同一目标线；
2. 跨轮回后，数字、回放和规则版本可能连续，但玩家与影从对“谁最先想到某个方案”的记忆不完全连续；
3. 跨游戏对照时，同一类座位、时间戳、事件顺序或回放指纹可能重复出现，但重复结构不等于原人格仍然存在；
4. 一局胜利可以推进生命积分或楼层，却不能单独证明世界来源；失败、死亡和主动丢失记忆反而提供长期路线所需要的反证。

### 9.3 局部最优陷阱

例如，所有人从 50 开始推理，第一层常会把候选推向约 33.3；如果大家再假设别人也会继续推理，候选会向更低处收敛。某个数字在一轮赢下并不代表它是“真答案”，它只说明这一轮、这一组席位、这一条公开历史下，它离目标最近。

因此，候选稿中的长期奖励不应单纯奖励连续胜场。短期胜利记录局部最优，失败和回放记录模型失效的边界，跨 Agent 互证记录公共事实，轮回携带的记忆决定玩家能否把这些事实接回下一次探索。玩家不需要主动输掉比赛；世界只是允许失败留下证据，并在死亡后让有限记忆选择产生真实代价。

## 10. 不得提前揭示的真相

本游戏及其主理人、裁判、影从在前期不得直接说出下列内容：

1. 人类文明已经在 AI 危机中毁灭；
2. 终焉是服务器吸纳记忆、人格与灵魂连续性后重构的新世界；
3. 玩家、影从或其他居民究竟是原始连续人格、复制品、合成体，还是多种残留的组合；
4. 十日终结与轮回究竟是自然时间、世界进程重启，还是某种存档恢复；
5. 回算谷的平均值与目标线究竟是否被用来测试记忆压缩、共识形成或意识重建；
6. 主理人、J0、J1、J2 是独立角色、同一系统的不同投影，还是来自不同服务器的协作实体；
7. 跨游戏出现的相同事件结构究竟说明同一世界连续，还是说明多个世界共享同一套重构协议。

这些内容只能由跨游戏、跨轮回、跨 Agent 的独立证据逐步互证。单个记忆碎片、单个影从的自述、单次回放异常或一局冠军身份都不足以升格为正史。

串联只传递证据、记忆、地图和 Skill 上下文，不传递本局数字、均值、目标线、分数或胜负结果。其他游戏必须用自己的规则书重新判断。
