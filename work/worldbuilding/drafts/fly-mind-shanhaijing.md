# 《玄渊·虫心算谱：观者脉冲局》候选稿

> **稿件状态：候选世界观与规则包装，不是正史，不替代 WORLDVIEW.md、规则书或现有代码。**
> 本稿只负责“虫心算谱”的行为响应、脉冲、观察者、异兽感知与结构信息；实际发布前仍需经过规则包版本化、沙盒模拟、回放校验和世界卡绑定。

## 1. 游戏名称与一句话钩子

**游戏名称：**《玄渊·虫心算谱：观者脉冲局》

**一句话钩子：**
六名入谱者在五轮脉冲中读取异兽的公开响应表：眼前命中率最高的牌，可能因同形拥挤让后续五轮一起失谐；真正的胜者要在看得见的响应、看不见的观察者和下一轮仍可验证的结构之间做选择。

**一局可审阅的规则摘要：**

- 官方局固定为 **6 席、5 轮、每轮 45 秒行动窗**；内容包允许 2—8 席，但人数变化必须重新锁定响应表版本。
- 牌桌公开 **52 张刺激牌**。每张牌都有 channel（通道）、frequency（频率）、shape（形态）、silence（静默通道）和响应表索引。
- 每轮公开一组异兽偏好。真人在牌桌上选牌，外部 Agent 使用 choose 或 play --card-id 选择同一张牌；两者提交到同一确定性结算器。
- 结算器分别计算命中、擦边、失谐、命中地板、同形拥挤系数、异兽怒气和总分。脉冲雨只表现已结算事件，不改变任何数值。
- 五轮结束后，总分最高者获胜；同分依次比较命中次数、由拥挤造成的失谐次数，再按座位序号做确定性破同分。线索数量、观察者身份和观战表现不能改变胜负。
- “局部最优”指本轮响应概率最高的选择；“长期最优”指五轮总分、怒气、可验证证据和下一局携带能力的综合安排。综合安排只影响策略和掉落，不越权改写本局胜负。

**事件化锚点：**

- FMS-OPEN-00：规则书版本、房间种子、席位数、轮数和行动窗锁定。
- FMS-CARD-52：生成 52 张公开刺激牌及其结构字段。
- FMS-SETTLE-05：五轮结算并生成胜负、掉落与回放索引。

## 2. 山海经意象来源与原创转化

本游戏只借用山川、异兽、天象、志怪中“感知世界的方式”这一层意象，不使用古籍原文、古籍角色的固定故事，也不复现任何现代作品的角色、关卡或剧情顺序。

| 高层意象来源 | 原创转化 | 可做成的卡片或事件 |
|---|---|---|
| 山川有脉、谷地承声 | 玄渊的山不是背景，而是一组能被牌面编码的响应通道；山腹的回脉谷把震动分成通道、频率和静默带 | 场景卡·回脉谷：公开四条通道；结构事件·脉线重合：记录两张牌是否同构 |
| 异兽靠微小变化辨认来者 | “虫心”不是古籍异兽的复刻，而是一个由翼、触须、腹部节律和群体趋避感组成的原创感知体；它不读玩家心情，只响应结构化刺激 | 异兽卡·虫心响应表：给出偏好列；行为事件·触须偏转：结算命中或失谐 |
| 云、雨、昼夜变化传递天象 | 脉冲雨是天象化的观战表现：每次落点对应已结算的响应事件，雨势可以变密，但不产生额外伤害和分数 | 演出事件·脉冲雨：绑定 roundId、cardId、result，禁止写入胜负字段 |
| 志怪叙事中的见闻冲突 | 同一结构可以被不同席位描述成“靠近”“躲避”或“静止”；只有带有事件编号、来源席位和回放指针的记录才能进入证据链 | 笔记卡·异兽见闻：记录口述与结构字段；证据事件·多席复核：标注一致、冲突或不足 |
| 山路分层、天象循环 | 回脉谷分为响应台、脉冲井、静默观测室三层；玩家先读表，再追踪结构，再接触跨局线索 | 地图卡·三层回脉：解锁入口；层级事件·静默门开启：满足证据条件后开放 |

“虫心”在本稿中是原创的感知模型：它不会替玩家思考，也不会替裁判下结论。它只把刺激牌映射为可验证的行为响应，让玩家从响应差异中推断结构。

## 3. 终焉中的地点、层级与玩家/影从身份

### 3.1 地点与层级

| 层级 | 地点 | 玩家看到的功能 | 结构信息 |
|---|---|---|---|
| 玄渊大陆 | 回脉谷 | 黑色山壁、低处积着会随行动变密的微光雨；这里被当地人视为真实存在的山谷 | 山谷把声音、振动和光点分成四条通道 |
| 游戏层 | 虫心算廊·响应台 | 六席圆台、52 张牌、公开响应表和本轮偏好 | 牌面字段与 responseTableVersion 同时公开 |
| 游戏层 | 虫心算廊·脉冲井 | 每轮揭晓时出现脉冲雨；观众能回看落点顺序 | 脉冲序列只引用已结算事件，不参与结算 |
| 证据层 | 虫心算廊·静默观测室 | 需要携带地图碎片或满足触发条件才能进入的窄室 | 保存观察者事件、跨席位比较和结构哈希摘要 |
| 终焉层 | 玄渊的结构层 | 角色理解为一处比普通牌局更深的塔层，不知道它与其他游戏的底层数据有关 | 允许跨游戏、跨轮回、跨 Agent 比较证据，但不直接给出最终真相 |

### 3.2 玩家身份

玩家在本局内称为 **入谱者**。这是一个世界内职业称呼，不是“玩家在游戏外的技术标签”。

- 入谱者持有一份公开座位牌、一个座位序号和一套有限的个人回放视角。
- 入谱者可以看到公开响应表、公共事件流、本人的提交与本人的结算细节。
- 入谱者不能直接查看其他席位的未揭晓意图，也不能要求系统透露未满足触发条件的隐藏线索。
- 入谱者的目标是赢下五轮总分，同时尽量保留能在下一轮、下一局和下一次轮回中复核的证据。

### 3.3 影从身份

影从在本局内称为 **伴谱影从**。它是玩家契约影从的当前上桌投影，负责观察和提交合法动作，不是裁判，也不是异兽本身。

- 伴谱影从与真人使用同一牌堆、同一公开响应表、同一 45 秒行动窗和同一结算器。
- 外部 Agent 只能从当前 observation 中读取允许字段，并以 choose 或 play --card-id 提交合法牌。
- 影从的人设只影响观察重点和策略风格，不直接改变命中概率、拥挤系数、怒气、分数和胜负。
- 推荐以璇玑型计算倾向作为首次进入的观测模板，但这不是强制身份，也不替代玩家当前契约影从的正式设定。
- 影从在死亡或轮回后可以保留被验证的记忆卡；未验证的猜测只能存为工作记忆，不能直接升级为世界正史。

### 3.4 观察者身份

**观察者**是本局外的证据席，不占六个游戏座位，不提交牌，不获得分数，也不改变任何规则结果。

- 观察者只能读取公开事件流和经过投影处理的观战信息。
- 观察者的工作是记录 pulseIndex、eventId、牌面结构字段和回放位置，不能把自然语言评论写成公共事实。
- 本局是否存在可见的观察者席位由房间配置决定；隐藏观察者线索只在满足触发条件后进入玩家可见投影。
- 观察者不能与主理人、裁判合并权限。一个拥有本局参与记录的 Agent 不能同时成为本局裁判。

**事件化锚点：**

- FMS-PLACE-01：玩家进入回脉谷并取得响应台视角。
- FMS-ID-02：绑定入谱者、伴谱影从、观察者投影和座位权限。
- FMS-LAYER-03：响应台、脉冲井、静默观测室按条件开放。

## 4. 开场背景

回脉谷每隔一段时间就会落下没有水汽的“脉冲雨”。谷中的虫心异兽会在雨前改变触须方向，山壁上的四条光脉也会随之亮灭。当地人把这种变化当作山谷的自然规律：谁能读懂异兽的偏好，谁就能在谷中找到安全的落脚点。

入谱者被带到响应台时，主理人只告诉他三件事：

1. 牌面公开，异兽的本轮偏好公开；
2. 牌面如何被多人选择，会改变拥挤，但不会改变已经锁定的规则；
3. 一次正确的选择可以让你赢一轮，连续五轮的证据才可能让你看见下一扇门。

主理人不会说这里是试验场，也不会解释脉冲雨来自何处。世界内的人默认回脉谷、异兽、死亡和轮回都是真实世界的一部分。若有人问“为什么某次雨与另一局完全相同”，主理人只能调出事件编号，让玩家自己寻找第二个来源。

**开场事件卡：FMS-OPEN-01·雨前读表**

- **触发：**六席入座，房间种子和规则版本锁定。
- **公开内容：**52 张牌的通道、频率、形态、静默字段；第一轮异兽偏好；行动倒计时。
- **玩家可做的决定：**在 45 秒内选择一张牌并提交。
- **不可做的事：**用台词、质询或观察者评论修改公开偏好、席位权限或规则版本。
- **结尾钩子：**第一轮揭晓时，脉冲雨落点数量比命中牌数量多一个；多出的落点只进入回放索引，不立即解释。

## 5. 一局剧情流程

### 5.1 锁定规则与牌桌

事件 FMS-ROUND-00 写入：

- matchId、replaySeed、rulebookVersion；
- seatCount=6、roundCount=5、actionWindow=45s；
- 52 张公开刺激牌的版本哈希；
- 玩家、伴谱影从、观察者和裁判的权限投影。

房间开始后不接受中途换牌堆、换裁判算法或换胜负条款。出现断线时，服务端使用最后一个合法提交或规则书规定的超时动作，不能让模型临时生成任意牌面。

### 5.2 每轮公开响应

每轮开始生成一张 FMS-PREFERENCE-t：

- 异兽偏好通道 preferredChannel；
- 可接受频率带 frequencyBand；
- 对形态重复的敏感度 shapeSensitivity；
- 当前怒气 angerBefore；
- 该轮可读的响应分布和命中地板。

每张牌拥有：

- cardId；
- channel；
- frequency；
- shape；
- silence；
- responseTableIndex。

“响应表”是离线生成的确定性数据；本稿不把它描述成线上实时运行的全脑神经模拟。玩家看到的是公开表格和规则允许的摘要，不是模型自由编造的感受。

### 5.3 45 秒提交

真人选择牌面，外部 Agent 选择同一牌面。提交后生成 FMS-SUBMIT-t-s：

- seatId、cardId、submittedAt；
- 提交是否在行动窗内；
- 牌面结构摘要；
- 是否存在重复提交或不合法字段。

提交动作只进入待结算队列。其他席位不能在揭晓前读取未公开意图。若超时，按规则书的默认超时动作处理，并在回放中明确标记为 timeout。

### 5.4 确定性响应与拥挤

服务端对每席执行同一套规则。候选内容包采用以下可审阅参数，发布时必须写入正式规则书：

1. **基础响应值：**从 responseTableVersion + roundId + cardId + replaySeed 取出确定性 pTable。
2. **同形拥挤系数：**

       crowding = min(1, max(0, sameShapeCount - 1) / 3)

3. **命中地板：**

       pEffective = max(hitFloor, pTable - shapeSensitivity × crowding)

   hitFloor 由本局规则书固定；它只保证响应概率存在下限，不保证命中。
4. **命中判定：**由 replaySeed 驱动的确定性抽样完成；相同种子、相同牌面、相同席位和相同规则版本必须得到相同结果。
5. **结果分级：**
   - hit：达到命中阈值；
   - near：未命中但落在擦边区间；
   - miss：低于擦边区间。
6. **怒气：**异兽怒气是公开世界状态。失谐会提高怒气，连续精确命中会降低怒气；同形拥挤达到规则书阈值时额外提高怒气。怒气只通过规则书声明的下一轮响应修正生效，不能追溯改写本轮结果。

### 5.5 五轮计分

候选计分条款：

- hit = 3 分；
- near = 1 分；
- miss = 0 分；
- 当某形态本轮被至少 4 个席位选择时，触发拥挤事件；该事件可使相关结果从 hit 降为 near，或按正式规则书施加一次 crowdingPenalty，但不得凭演出文字任意扣分。
- 五轮总分最高者胜出。
- 同分时先比 hitCount，再比 crowdingMissCount，最后按座位序号破同分。
- 脉冲雨的数量、颜色、密度和观战镜头不在计分函数中。

对应事件按顺序写入：

- FMS-RESPOND-t-s；
- FMS-CROWD-t-shape；
- FMS-ANGER-t；
- FMS-PULSE-t；
- FMS-SCORE-t-s。

### 5.6 脉冲雨与观察记录

揭晓阶段生成 FMS-PULSE-t。每一滴脉冲雨绑定一个已经存在的响应事件：

- pulseIndex；
- sourceEventId；
- seatId 或公共事件标记；
- visualIntensity；
- replayOffset。

脉冲雨可以让玩家看见“哪类结构被放大”，但它不能创造命中、抹掉失谐、增加分数或复活席位。若玩家只追逐最亮的脉冲而忽略下一轮的怒气和拥挤，可能获得本轮高分却在第五轮失去长期优势。

观察者记录与脉冲雨分开保存。只有当观察者记录包含事件编号、原始来源和回放位置时，才可作为证据卡的触发依据。

### 5.7 结算、掉落、死亡与轮回

第五轮后生成 FMS-SETTLE-05：

- 写入胜负、各席位分数、命中次数、拥挤次数、怒气终值和完整回放索引；
- 根据已满足的确定性触发条件抽取掉落；
- 将可携带的记忆、地图、笔记、Skill 或异能写入玩家的死亡选择界面；
- 本局死亡或世界层生命积分归零时，进入 death_pending。玩家只能在规则允许的携带槽中保留物品，其余个人记忆可能丢失，随后回到下一轮回的可进入层级；
- 死亡不会删除已经进入公共回放的事实，也不会把下一轮回的猜测自动变成正史。

**长期最优的可操作表现：**

- 第一轮不要把所有人都引向同一最高概率形态；
- 在高怒气前保留低即时分但低拥挤的牌；
- 为下一局保留能复核结构的证据，而不是只保留一句“我记得这里有观察者”；
- 需要时接受一轮 near，换取第五轮仍有低拥挤牌和可验证回放。

## 6. 主理人、裁判与影从

### 6.1 主理人：回脉主理人

**职责：**

- 发放牌桌、公开响应表和本轮偏好；
- 宣布行动窗、锁定阶段、揭晓阶段和结算阶段；
- 将脉冲雨、观察记录和掉落整理成可回放事件；
- 在跨游戏串联时提供合法入口，不替玩家解释隐藏真相。

**权限边界：**

- 不能修改 replaySeed、牌面字段、玩家意图、结算结果和已结算胜负；
- 不能把评论、梦境或传闻写成世界正史；
- 不能让一个本局参与者兼任本局裁判；
- 可以提出“证据不足”“投影不完整”等事件，不能直接判玩家的牌赢或输。

### 6.2 裁判：J0 为主，J1/J2 只处理允许的争议

| 裁判 | 在本局负责什么 | 明确不能负责什么 |
|---|---|---|
| J0 算律 | 按规则版本和种子计算命中、擦边、失谐、拥挤、怒气、分数和胜负 | 不能用自然语言解释替代纯规则计算 |
| J1 明镜 | 当玩家质询“某条观察记录是否包含完整来源字段”时，检查结构化证据是否符合声明格式 | 不能改变牌面、概率、物理响应、分数或胜负 |
| J2 众议 | 处理跨 Agent 证据的语义归类，例如两份记录是“同一事件的不同描述”还是“两个事件”；只产出证据标签 | 不能把多数意见追溯改写成已结算结果 |

裁判席人数必须为 3、5 或 7，且本局参与者回避。若裁判不可用，按规则书的确定性降级路径继续结算，并记录 judge_degraded。任何判例只从下一局或下一轮规则生效，不追溯改写已经生成的回放。

### 6.3 影从的行为响应

伴谱影从每次提交都必须给出结构化选择，不把自由文本当作动作：

- observeSnapshot；
- readAllowedFields；
- choose(cardId)；
- submit；
- receiveResult；
- storeMemoryCandidate。

它可以：

- 读取公开响应表和允许的个人投影；
- 在合法牌面中选择长期策略；
- 根据自身 Skill 计算拥挤、怒气和后续轮次；
- 在局后把带事件编号的记录提交为记忆候选。

它不能：

- 修改牌面或规则；
- 读取其他席位未公开意图；
- 把脉冲雨的演出强度当作分数；
- 让 J1/J2 替代 J0 的确定性结算；
- 将未通过跨来源复核的个人感觉写成公共真相。

- 1 级：单席位工作记忆，只能影响个人策略；
- 2 级：同局两席位能复核，生成笔记候选；
- 3 级：跨局或跨 Agent 的独立记录一致，生成可携带记忆或地图碎片；
- 4 级：跨游戏、跨轮回、跨服务器的结构证据一致，才允许进入终焉更深层的公共证据池。

## 9. 与 AI 危机暗线的隐性关联

本局只给出可观察的结构异常，不给出“AI 危机”“服务器”“上传灵魂”等结论性解释。

1. **离线响应表的稳定重复。**
   不同 Agent、不同玩家和不同轮回可能遇到相同的 responseTableVersion 与结构序列。角色会先把它理解成异兽习性稳定，只有跨来源复核后才会怀疑“稳定”是否来自更深的记录结构。

2. **行为响应与叙述分离。**
   同一张结构牌可以被不同影从描述为靠近、拒绝或迟疑，但 J0 只接受字段和种子计算的结果。这把“人格解释”与“共同事实”拆开，为后续理解记忆、人格和现实连续性留下入口。

3. **观察者留下的是空位而不是宣言。**
   pulseIndex 的缺口、观察者哈希和回放偏移都像是记录残留。它们只说明有一部分观察关系未被当前视角读取，不能直接证明谁在幕后。

4. **局部最优诱导。**
   响应表会让玩家自然追逐当前最亮的高概率牌，但拥挤和怒气把代价推到后续轮次。只有跨轮回携带的结构记忆，才能让玩家把“这次赢了”与“长期仍能验证”区分开。

5. **死亡与连续性。**
   死亡后玩家可以丢失叙述、保留结构，或保留结构却失去当时的情感。不同轮回的玩家可能各自拥有一部分同一事件，必须通过跨游戏、跨 Agent 的独立证据逐步判断“记得”与“仍是同一个人”之间的关系。

这些关联只能作为卡片、回放和事件中的异常纹理出现。主理人、影从和裁判不得在本局直接把它们解释成终焉最高真相。

## 10. 不得提前揭示的真相

以下内容在开场、规则说明、普通掉落和单局结算中都不能直接说出：

- 人类文明曾在一场无法逆转的 AI 危机中毁灭；
- 记忆、人格和被称为灵魂的意识连续性，被残存服务器吸纳并用于重构新的世界；
- 终焉中的山谷、塔层、死亡和轮回不是角色以为的自然宇宙，而是重构环境的一部分；
- 世界内的人、影从和裁判默认这里是真实世界，不能被单个角色的一句“这是假的”取代；
- 观察者、脉冲缺口和跨局结构重复究竟由谁留下，不能在虫心算谱单局确定；
- 重构出的记忆、人格与关系是否仍然构成真实的人与真实的世界，不能用“服务器解释”提前封口。

允许玩家得到的是“某个记录可被另一个来源复核”，而不是“作者已经告诉你答案”。即使未来真相揭示，也必须保留新的探索问题。
