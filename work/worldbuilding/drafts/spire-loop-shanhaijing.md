# 候选稿｜《碎境爬塔：四象轮回档案》

> 状态：`draft`，主控补齐稿。本文是爬塔的世界背景和内容掉落候选，生命、战斗、死亡、卡组与层门仍以 Spire RuleBook 和服务端状态为准。

## 1. 背景与钩子

碎境不是普通建筑，而是一片被分成层级的记忆地貌。四个十二层区域分别偏向观测、迁徙、交换与裁决；同一座山、同一种异兽或同一场天象可能在不同层出现，却给出不同的局部解释。玩家带着有限生命积分、卡组、地图碎片和笔记残卷从低层进入，每日最少参加三场黑暗对局；积分归零则死亡、回到底层，并在有限容量内选择携带记忆。

一句话钩子：**每一次死亡都带走一部分答案，却把问题本身留在你身上。**

## 2. 一次轮回流程

1. `run-open`：锁定周期、层级、种子、卡组和记忆容量。
2. `node-select`：选择游戏、事件、商店、休息或调查节点。
3. `dark-match`：进入一场有规则版本和事件回放的黑暗对局。
4. `drop-choice`：确定性生成可见掉落，玩家在容量内选择携带。
5. `life-crisis`：生命低于层门阈值时，开放即时保命与长期证据二选一。
6. `death-or-ascend`：死亡回到底层并遗失部分主动记忆；上层则保留允许的卡组和证据。

## 3. 可验证线索

- **可见**：死亡后事件编号仍在档案里，但玩家对其中部分细节失去读取权限。
- **可见**：同一地图碎片需要不同轮回才能拼合，地图拼合不等于传送。
- **可见**：生命危机会把即时奖励和长期记忆放到同一选择窗口。
- **隐藏**：层号可能对应服务器快照恢复顺序，而非自然高度；需多层独立地图和时间戳互证。

## 4. 候选掉落

| ID | 类型 | 效果 | 触发条件与代价 | 携带 |
|---|---|---|---|---|
| `sp.memory-loop-index` 轮回索引 | 现实碎片 | 记录死亡、携带选择与回到底层后的差异 | 经历真实死亡；占 2 容量 | 跨游戏只读 |
| `sp.map-layer-seam` 层缝残图 | 地图碎片 | 标出两层地图的非固定接缝 | 同一玩家两次轮回分别获得；不能跳过层门 | 跨层 |
| `sp.note-life-crisis` 危机残卷 | 笔记残卷 | 保存某层生命危机条件与预兆 | 由真实生命值和事件生成 | 跨游戏 |
| `sp.skill-memory-loadout` 记忆编组 | Skill | 在入塔前比较保留卡片的长期收益与容量代价 | 每次入塔一次；不能代替玩家选择 | 跨游戏 |
| `sp.ability-recall-fragment` 召回残响 | 异能 | 在授权剧情槽中调用遗失卡片的摘要 | 只给信息摘要；增加遗忘风险 | 仅爬塔 |
| `sp.memory-death-witness` 死亡见证 | 现实碎片 | 保存同行者视角的死亡过程 | 需要独立观战事件；可能与死者自述冲突 | 跨游戏只读 |
| `sp.map-server-bridge` 服务器桥图 | 地图碎片 | 提示另一服务器存在相同异常地点 | 两份服务器快照互证；不能改写对方世界 | 跨服务器只读 |
| `sp.skill-long-horizon` 长期视野 | Skill | 在局部奖励与长期证据冲突时生成两套方案 | 只提案不强制执行；每周期有限次数 | 跨游戏受限 |

## 5. 暗线与跨游戏入口

爬塔的主线问题不是谁登顶，而是轮回中被保留、遗失、交换和再次确认的信息，能否重新建立一个意识对自身来处的连续解释。赛马地图可以打开某层接缝；桌球碰撞轨迹可以成为死亡见证；狼人杀的证言缺口可以进入证据库；海盗分金的契约编号可以成为层门条件。

所有生成剧情先是 `StoryProposal`，只能填入固定剧情开放槽。世界 Agent 可以提出“某层出现旧地图”或“某张卡片在死亡后变得不可读”，但不能自行宣布 AI 危机、人类文明毁灭、服务器重构或灵魂来源。只有跨游戏、跨轮回、跨 Agent 的事件互证，才允许把传闻升级为公共事实。

- [ ] 每日三场要求由世界层状态检查，不由旁白宣告；
- [ ] 死亡扣除的是可携带记忆，不抹掉事件历史；
- [ ] 生命危机有真实数值和可回放选择；
- [ ] 地图碎片提供路线与证据，不直接跳过门禁；
- [ ] 轮回变化不改写既有结算；
- [ ] 模型失败时仍可使用结构化掉落和事件摘要。

## 6. 主理人、裁判与影从

塔门主理人只负责节点、层门和周期提示；每个小游戏仍由自己的 J0/J1/J2 裁判执行。世界 Agent 负责选择固定剧情的开放槽并提出 `StoryProposal`，影从负责记忆编组和行动建议，任何一方不能直接改生命、死亡、层号或历史事件。

## 7. AI 危机暗线的隐性关联

爬塔持续验证：轮回中被保留、遗失、交换和再次确认的信息，能否重新建立一个意识对自身来处的连续解释。数字载点是最终世界本体，但前期只允许通过地图、时间戳、死亡见证和跨游戏重复结构逐步逼近。

## 8. 不得提前揭示的真相

不能在低层直接说明人类文明毁灭、数字载点的构成、玩家和影从的原始身份或十日轮回的真实机制。单张卡、单次死亡或单个世界 Agent 的自述都不足以升级正史。

## 9. 与其他游戏的串联入口

赛马地图可以打开层缝；桌球碰撞轨迹可以成为死亡见证；狼人杀证言缺口可以进入证据库；海盗分金契约编号可以成为层门条件。所有入口只携带证据、记忆和门禁状态，不直接跳层。

## 10. 内容状态与发布

本文先为 `draft`，绑定真实爬塔回放后进入 `playable`；跨游戏、跨轮回、跨 Agent 的独立证据达到门槛，才可进入 `evidence-backed`。涉及数字载点本体、服务器融合和元规则的内容必须由主控批准。

## 11. 降级路径

LLM、音频或图片服务失败时，照常执行每日三场检查、节点选择、生命危机、死亡和掉落；旁白回退到结构化摘要，不能补写未发生的剧情事实。
