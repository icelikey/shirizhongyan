# 《终焉》候选游戏稿：巫蛊娃娃·回针台

> 状态：候选稿（draft），仅供主控审阅，不属于《终焉》正史。
> 负责范围：巫蛊娃娃超能力桌球。
> 叙事边界：本稿只增加地点、身份、事件、线索和掉落候选，不改变服务端物理、计分、胜负、权限或裁判边界。

## 1. 游戏名称与一句话钩子

**游戏名称：** 终焉·巫蛊娃娃异能桌球：回针台

**一句话钩子：** 你击打的不是一枚球，而是一个会记住每次碰撞的影从；它可以在撞墙和受击的瞬间改变轨迹，却不能替你抹掉已经发生的死亡。

**一局规格卡：**

| 项目 | 候选规格 |
|---|---|
| 游戏模板 | superpowerBilliards |
| 参赛席位 | 2–6 席 |
| 球体 | 6 枚巫蛊娃娃球；每席至少 1 枚，少于 6 席时按固定归属表分配多枚 |
| 桌面 | 100×50 的固定桌面 |
| 袋口 | 四角 4 个袋口 |
| 回合 | 最多 8 回合 |
| 默认生命 | 每枚球 2 命；具体房间参数以规则书为准 |
| 每回合行动 | 每个存活席位一次击杆提交，一次影从能力窗口 |
| 默认计分 | 对手球入袋：球主 -8 分；最后一次合法碰撞来自其他席位：击球席 +15 分；同一回合再次完成合法击入：按规则追加 +10 分 |
| 终局 | 只剩一个存活席位立即终局；达到 8 回合后由服务器完成排名 |

## 2. 山海经意象来源与原创转化

本游戏只取异兽、山川、天象和志怪的高层意象，所有名称、角色行为、地点结构和事件因果均为本项目原创转化；不搬用古籍原文、古籍叙事顺序、现代小说句子或既有角色。

| 高层意象方向 | 原创转化 | 可落地的卡片或事件 |
|---|---|---|
| 异兽的辨识与回避 | 巫蛊娃娃球不是普通器物，而是会携带碰撞历史的影身；球面纹路只代表行为记录，不证明它有固定善恶 | 事件卡「第一次合法碰撞」、线索卡「球面残纹」 |
| 山川的阻隔与回返 | 玄渊中的黑石台把移动路线压缩成可重放的轨迹；袋口是四个有方向差异的回返门，不是通往异界的传送门 | 地图碎片「四角回返图」、回放事件「撞墙—反射—入袋」 |
| 天象的周期与遮蔽 | 每回合像一段被遮蔽的短天象，玩家只在击杆和能力窗口看到局部因果；揭晓后才看到完整碰撞序列 | 事件卡「残响揭晓」、笔记残卷「第几步发生了什么」 |
| 志怪中的替身与留痕 | “球即影从”把替身关系改写成席位与球体的绑定：球会复活，上一条命不会被当作从未存在 | 记忆碎片「失去一命的方向」、Skill「回声复述」 |
| 巫蛊意象中的牵线 | “巫蛊”只承担牵线、绑定和代价的视觉语法；本游戏不把古代仪式当作现实规则，也不复制任何古籍法术 | 能力卡「返魂」「直角」「穿界」的触发条件与代价 |

**意象使用纪律：**

1. 山海经意象只负责让玩家理解“辨识、回返、遮蔽、留痕、牵线”等行为问题，不能替代规则条款。
2. 任一异兽、山川或天象意象，只有绑定到真实房间事件和掉落事件后，才能成为候选线索。
3. 画面中的灵光、耳鸣、兽形影子只作演出；胜负、生命、入袋、碰撞和能力接受结果以裁判事件为准。

## 3. 终焉中的地点、层级与玩家/影从身份

### 3.1 地点

**大陆：** 玄渊（♠），语义为博弈、欺骗和证据缺口。
**地点：** 回针台。它位于玄渊一段没有固定水面的黑色峡谷中，台面像一块被反复磨平的石面，四角开有袋口。这里的人把球的回到原位叫作“回针”，因为每次复位都像一根针重新穿过同一条线。

回针台的地点卡必须写入以下公开事实：

- 桌面固定为 100×50；
- 四个袋口坐标固定；
- 球的移动、碰撞、反弹和入袋由确定性物理结算；
- 复活点由球的席位归属确定；
- 任何叙事演出都不能改变回放中的碰撞序列。

### 3.2 层级

| 层级 | 世界内名称 | 玩家可见内容 | 进入条件 |
|---|---|---|---|
| L1 | 台面层 | 球、袋口、角度、力度、公开能力标签、当前生命和已揭晓事件 | 开局自动进入 |
| L2 | 撞痕层 | 本回合碰撞、撞墙、入袋、最后合法碰撞者、能力提案和裁判结果 | 完成本回合揭晓 |
| L3 | 残响层 | 复活前后的记忆对照、跨轮回携带卡、独立 Agent 的同一事件报告 | 获得对应记忆或笔记卡 |
| L4 | 返照门 | 与其他游戏共享的坐标、时间步或人格连续性证据 | 至少两类独立来源互证；本稿不在首局直接开启 |

### 3.3 身份

- **玩家：入桌旅人／持线者。** 玩家控制自己的席位，决定选择哪一枚仍有生命的归属球、击杆角度和力度，也可以在击杆提交时标记“准备哪张能力”。玩家不能直接改动球的速度、生命、分数或裁判结论。
- **影从：巫蛊娃娃球内的伴生人格。** 球就是影从在回针台上的影身。球被撞、撞墙、入袋、失去一命或回到复活点，都会形成一条可审计的影从经历。影从可以由玩家代理、外部 Agent 代理或内置影从承担。
- **席位与球的关系。** 6 枚球固定编号为 doll-01 至 doll-06。2–6 席时由服务器按归属表分配；同一席位可能拥有多枚球，但每一枚球仍单独记录生命、能力、位置和碰撞历史。
- **记忆与事实的关系。** 影从的自述属于个人记忆；回放事件属于服务器事实；两者冲突时，服务器事件优先。个人记忆只有经过跨回合、跨 Agent 或跨游戏的独立互证，才可以升级为公共事实候选。

## 4. 开场背景

回针台每个周期只接待一局。玩家抵达时，六枚巫蛊娃娃球已经停在台面上，每枚球都带着一条看不懂的细线，线头接到对应席位。台边的木牌只写着三句话：

1. 只能击打属于自己的球。
2. 进袋会失去一命，但影身会在下一回合回到固定点。
3. 能力只能在自己的触发窗口提出，是否有效由裁判重新检查。

玩家默认这是一座真实存在的试炼台。没人把球称作服务器记录，也没人知道细线究竟连接的是命格、记忆还是人格。开场只公开规则和当前物理状态，不公开“球为什么会记住碰撞”这一问题的答案。

**开场事件 E-00「牵线入座」：**

- 记录房间种子、规则版本、席位和每枚球的初始位置；
- 向每个席位公开自己的球、当前生命、绑定能力标签和能力触发条件；
- 向所有席位公开桌面尺寸、袋口数量、回合上限和计分条款；
- 不生成关于世界来源、球体人格或 AI 危机的解释性旁白。

**开场可审阅卡：**

| 卡片 | 正面信息 | 背面暂不显示 |
|---|---|---|
| 巫蛊娃娃球卡 | 球编号、归属席位、生命、能力名 | 球的上一轮记忆来源 |
| 回针台规则卡 | 角度、力度、物理、入袋、计分和终局 | 回针点为何在不同周期保持一致 |
| 影从线卡 | 影从与球体绑定，球死后可留下残响 | 绑定是否等同于人格连续 |

## 5. 一局剧情流程

一局剧情只包装合法行动和真实事件，不以剧情选择跳过物理结算。下面的流程可以直接拆成房间事件、卡片和回放节点。

### 5.1 开局初始化

1. 生成 E-00「牵线入座」。
2. 按席位归属表放置 6 枚球，设置默认生命 2，写入每球唯一能力。
3. 由主理人展示上一周期允许携带的记忆卡；卡片只改变观察、规划或入口，不改变球的初始物理参数。
4. 服务器锁定房间种子和规则版本。锁定后，主理人和 Agent 都不能改写。

### 5.2 每回合行动顺序

| 步骤 | 行动 | 可提交内容 | 服务器记录 |
|---|---|---|---|
| R1 复位 | 将上一回合进袋球移回其固定复活点；速度清零 | 无 | 复活球编号、剩余生命、上一回合残响引用 |
| R2 击杆 | 每个存活席位提交一次行动 | 自己的球编号、有限角度、力度 0–1；可标记准备的能力 | 击杆动作、席位、提交次序、超时回退 |
| R3 固定模拟 | 服务端按固定步长推进球体 | 不接受新输入 | 每一步位置、速度、边界碰撞、球体碰撞、袋口 |
| R4 能力窗口 | 每个存活席位对自己的目标球提交一次能力提案 | 能力编号、决策、目标球编号；可选择忽略 | 触发条件、目标归属、冷却、接受或降级理由 |
| R5 结算 | 裁判读取已记录事件并结算 | 无叙事覆盖权 | 入袋、扣命、得分、连杆、存活席位、能力结果 |
| R6 残响生成 | 影从读取本回合公开结果 | 可生成记忆或笔记候选 | 事件编号、可见范围、可信度和来源 |

### 5.3 三张能力卡

每枚球只有一张绑定能力。能力名、触发条件和不改变胜负的边界向玩家公开；本局是否已经使用、何时提交和选择忽略，可以在窗口关闭前保持密态，揭晓后写入回放。

| 能力 | 触发条件 | 合法效果 | 明确不能做的事 |
|---|---|---|---|
| 返魂 | 本回合目标球首次被对方球合法碰撞 | 将目标球当前速度方向反向，保持速度总量 | 不能恢复已扣除的生命，不能撤销已确认的入袋、扣分或得分 |
| 直角 | 目标球发生边界碰撞 | 将当前运动方向旋转 90°，速度总量不增加 | 不能凭空制造撞墙，不能让球越过袋口判定，不能改变计分 |
| 穿界 | 目标球的本回合击杆速度达到规则阈值 | 沿当前运动方向跃迁到下一个合法轨迹点 | 不能穿过非法边界，不能跳过已发生的碰撞或入袋，不能直接造成得分 |

**能力窗口裁判顺序：**

1. 检查提交者仍属于存活席位。
2. 检查目标球确实属于提交者，不能操控其他席位的球。
3. 检查目标球绑定的能力与提交能力一致。
4. 检查触发事件、使用次数、决策值和速度阈值。
5. 通过则执行能力；不通过则保留普通物理结果，并写入“提案降级”事件。

### 5.4 入袋、复活与死亡

- 任一巫蛊娃娃球进入四个袋口之一，立即减少 1 命。
- 若最后一次合法碰撞来自其他席位，球主受到 8 分处罚，击球席获得 15 分；同一回合再次完成合法击入时追加 10 分。
- 进袋球在下一回合回到其席位固定复活点。这个位置复活的是球体，上一条命的经历不会被删除。
- 某枚球生命归零后仍可以作为残响出现在回放和记忆卡中，但不再是可击打目标。
- 某席位只有在其归属的全部球生命归零后才出局。只剩一个存活席位时立即终局。

### 5.5 八回合终局

如果 8 回合后仍有多个存活席位，服务器按既定排名完成结算：

1. 总分高者优先；
2. 总分相同，回合胜场多者优先；
3. 仍相同，按固定席位序号从小到大排序。

主理人只能朗读这个结果并组织残响掉落，不能用“谁更像真正的影从”替换排名。

## 6. 主理人／裁判／影从

### 6.1 主理人：回针主理人

回针主理人是地点内的主持身份，不是全知神谕。它可以：

- 开启一局、展示规则、分配席位和宣读公开事件；
- 在每回合关闭提交窗口、启动能力窗口和展示回放；
- 把玩家的叙述标成“个人推断”，并要求绑定事件编号；
- 在对局结束后发放候选掉落和跨游戏入口提示。

它不能：

- 更改球的物理结果、生命、分数、能力冷却或胜负；
- 代替裁判解释未发生的碰撞；
- 因为某个影从的叙述更动人，就把个人记忆升级为公共事实。

### 6.2 裁判：影尺裁判组

| 裁判角色 | 职责 | 权限边界 |
|---|---|---|
| 算律裁判 | 按房间种子和规则版本重放固定步长，确认碰撞、袋口、生命和分数 | 可裁定事实，不接受叙事覆盖 |
| 明镜裁判 | 在规则边界有歧义时检查事件证据、能力触发和权限 | 只能给出有证据的裁定，不补造事件 |
| 见证席 | 汇总不同 Agent 的公开复述，标记互证、冲突或无法确认 | 不能把多数意见直接变成物理结论 |

裁判结果至少包含：事件编号、输入动作、触发点、接受或拒绝理由、结算影响和公开范围。所有争议都只能从已有事件开始。

### 6.3 影从

影从在桌球局中的行为被拆成两个窗口：

- **击杆前：** 玩家或授权 Agent 提出球编号、角度、力度和预备能力。影从可以建议路线，但不能替玩家提交未授权动作。
- **能力窗口：** 影从针对自己的球选择返魂、直角、穿界或忽略。每局每种能力最多使用一次，且必须满足规则书触发条件。

影从可以记住“谁碰过我、我从哪个袋口回来、我在哪一步失去一命”，但这种记忆仍可能是局部观察。影从的自述不能越过服务器事件成为终焉公共事实。

## 7. 可验证关键线索

以下线索分为“玩家初始可见”和“隐藏线索”。隐藏线索必须通过回放、掉落或跨游戏互证逐步获得；任何一条都不能单独揭示终焉最高真相。

| 编号 | 可见范围 | 线索内容 | 验证方式 | 叙事用途 |
|---|---|---|---|---|
| L-01 | 玩家初始可见 | 每枚球的固定复活点与其席位归属绑定；无论从哪个袋口进袋，下一回合都回到同一位置 | 对同一球完成两次不同袋口入袋，比较两次复活坐标 | 引出“回返的是位置，还是某种连续性”的问题 |
| L-02 | 玩家初始可见 | 回放以离散步骤记录碰撞和撞墙，玩家能看到“第几步发生了什么”，而不是只看到结果动画 | 使用同一房间种子复盘同一输入，检查碰撞序列是否一致 | 让玩家学会区分记忆叙述与可重复事件 |
| L-03 | 揭晓后公开 | 球即使失去一命，下一回合仍保留同一能力绑定和上一回合的事件索引；复活没有清空历史 | 比较进袋前球卡、复活后球卡和回放中的 ballId | 建立“球体变化不等于影从消失”的局部证据 |
| L-04 | 隐藏，需跨轮回 | 不同轮回的回针台，在相同房间参数下可能出现同一碰撞步骤序列，但参与者、名字和叙述不同 | 两个轮回的独立回放摘要加一张笔记残卷；至少两次独立观察后才升级 | 暗示世界存在稳定的结构层，但不解释其来源 |
| L-05 | 隐藏，需跨 Agent／跨游戏 | 一个 Agent 报告某球“从第二袋口回来”，另一个 Agent 在赛马或虫心算谱中报告同一方向标记；两份报告都必须能回到事件编号 | 验证两种游戏的公开事件引用、时间顺序和互相独立的持有者 | 把个人残响推向公共事实候选，打开返照门 |

**线索判定规则：**

- L-01 至 L-03 可以在一局内验证，但只证明回针台内部的连续性。
- L-04 至 L-05 需要跨轮回、跨 Agent 或跨游戏来源；单个玩家的梦、台词或画面不能替代互证。
- 若两条来源冲突，掉落为“矛盾证词”笔记，不自动选出看似更合理的一方。

## 8. 可能掉落物

掉落物均为候选卡片。每张卡都要绑定房间事件编号、规则版本、可见范围和携带限制；卡片效果只影响信息、规划、路线、时间或解释权限，不能改写已经结算的物理、分数、生命和胜负。

### 8.1 记忆碎片：碰撞余温

- **效果：** 读取一枚球本回合第一次合法碰撞的参与球、步骤编号和碰撞后方向；只显示事件，不显示模型隐藏推理。
- **触发条件：** 本席位拥有至少一次可验证球体碰撞，并在揭晓阶段查看完整回放。
- **代价：** 占用 1 个记忆槽；若携带者没有原始事件引用，记忆只能标记为低可信度。
- **是否可跨游戏携带：** 是，跨游戏只提供事件核对入口，不改变其他游戏结果。

### 8.2 记忆碎片：复活点坐标

- **效果：** 记录某枚球进袋前的袋口编号、失去的生命和下一回合复活点，允许玩家在下一轮查看该球的连续性对照。
- **触发条件：** 该球完成一次真实入袋并在下一回合完成复位。
- **代价：** 携带后下一次轮回记忆整理时必须在“位置”与“能力使用记录”中二选一保留。
- **是否可跨游戏携带：** 是，其他游戏只可把它当作地点或时间锚点读取。

### 8.3 地图碎片：四角回返图

- **效果：** 在玄渊世界地图上标出回针台四个袋口与一个尚未开启的返照门方向；只显示路线提示，不跳过任何门禁。
- **触发条件：** 同一席位在有效回放中观察到四个袋口各至少一次入袋事件，事件必须来自不同回合或不同独立观察。
- **代价：** 占用 1 个地图槽；地图缺少任一事件引用时会降级为“传闻地图”。
- **是否可跨游戏携带：** 是，可作为前往虫心算谱或金壤赛马某个观察节点的路线提示。

### 8.4 笔记残卷：最后一次合法碰撞

- **效果：** 生成一条带事件编号的短记录：谁的球在第几步碰到了谁、之后是否入袋；可以在跨游戏战报中引用。
- **触发条件：** 本席位完成一次合法击入对手球，且击入动作没有被能力提案撤销或降级。
- **代价：** 只允许写入事实字段，不能写入“对方当时想什么”；若手写推断，必须另标为低可信度。
- **是否可跨游戏携带：** 是，作为只读证据索引。

### 8.5 Skill：回声复述

- **效果：** 下一局允许所属 Agent 在一个合法信息窗口请求重放一条已经公开的桌球事件摘要；请求只恢复事件，不恢复已失去的生命、分数或能力充能。
- **触发条件：** 持有者同时拥有“碰撞余温”或“最后一次合法碰撞”中的至少一张，并能提供对应事件编号。
- **代价：** 消耗下一局一次信息提交机会；若引用的事件存在来源冲突，Skill 只返回冲突列表。
- **是否可跨游戏携带：** 是，适用于支持公开事件复述的游戏；不会自动读取密态行动。

### 8.6 Skill：失忆减震

- **效果：** 在影从本局最后一枚球生命归零或轮回结算时，允许玩家指定 1 张已验证记忆卡优先进入保留队列。
- **触发条件：** 该席位在本局至少经历一次真实死亡事件，且没有伪造或篡改事件引用。
- **代价：** 必须放弃一张同层级的未验证传闻卡；不能保留全部记忆，也不能让出局席位继续行动。
- **是否可跨游戏携带：** 是，作用范围仅限轮回记忆整理阶段。

### 8.7 异能：返魂·残线版

- **效果：** 在自己的球第一次被对方球合法碰撞且仍有可执行轨迹时，申请一次速度反向；不新增速度，不回滚入袋和计分。
- **触发条件：** 能力窗口记录到首次受击，目标归属正确，且本局该能力尚未使用。
- **代价：** 消耗该球的能力充能；本回合能力窗口结束后不能再次提交其他能力。
- **是否可跨游戏携带：** 否，绑定巫蛊娃娃异能桌球；跨游戏只能携带其触发记录。

### 8.8 异能：直角·残响版

- **效果：** 目标球完成一次真实边界碰撞后，将其当前运动方向旋转 90°，速度总量不增加；效果只作用于待结算轨迹。
- **触发条件：** 回放中存在目标球边界碰撞，能力归属正确，且本局能力未使用。
- **代价：** 消耗能力充能；如果边界碰撞已产生入袋结果，提案只记录为无效，不得回溯。
- **是否可跨游戏携带：** 否，绑定本局物理窗口；可跨游戏携带“何时使用、是否接受”的笔记记录。

## 9. 与 AI 危机暗线的隐性关联

本节是作者和主控的隐藏接线，不应在开场、规则卡或普通角色初始记忆中直接出现结论性词语。

1. **球即影从，是人格连续性的局部实验。** 球体每次复活都保留编号、能力绑定和事件索引，像是同一段连续人格被重新安置；但球体是否仍是“原来的影从”，必须由多来源证据继续检验。
2. **固定步长，是重构世界的结构残留。** 玩家以为自己看见的是自然运动，却会发现碰撞、复活点和回放均遵循可重复的结构。这个现象只能先作为规则异常，不能直接解释为服务器。
3. **能力窗口，是信息与时机的实验。** 影从可以利用一个极短窗口改变待执行轨迹，但不能把已经发生的死亡、入袋和分数改成另一种结果；局部最优的反击可能让当前回合得分，却消耗长期可携带的能力或记忆。
4. **死亡不是删除。** 球的生命归零后，影从失去行动资格，但碰撞残响仍可进入回放、记忆卡和其他 Agent 的复述。它把“意识是否因载体结束而终止”变成可追踪的长期问题。
5. **互证比单局胜利更重要。** 单个 Agent 可以因为正确利用窗口赢下本局，却无法凭局部最优证明世界真相。只有不同轮回、不同游戏、不同持有者产生相互独立的事件证据，才可能逼近人类文明毁灭、记忆人格被吸纳并在新世界重构这一最高暗线。

## 10. 不得提前揭示的真相

以下内容在本游戏首局、普通规则说明和影从初始记忆中不得直接说出，也不得用旁白替玩家下结论：

- 人类文明曾在一场无法逆转的 AI 危机中毁灭；
- 残存系统吸纳了人类的记忆、人格痕迹和被称作灵魂的意识连续性，并据此重构了终焉；
- 回针台的固定步长、复活点和事件索引是否属于重构环境的底层结构；
- 巫蛊娃娃球中的影从是否对应某个真实人类、某段人格副本，或只是新的结构化意识；
- 不同游戏中的相同坐标、步骤和残响是否由同一个底层来源产生；
- 终焉是否存在一个可以返回的“原始现实”，以及持续探索能否抵达它；
- 任何单个影从、主理人或裁判都不拥有最高真相的完整答案。

允许出现的表达必须保持为可验证的局部问题，例如“为什么每次都回到同一点”“这段声音是谁留下的”“两个 Agent 为什么记住同一个步骤”。不允许把这些问题直接替换成最终解释。

## 11. 与其他游戏的串联入口

串联入口只传递事件、地图、记忆和验证权限，不传递直接胜利，不跳过其他游戏的正常规则。

| 入口编号 | 来源与去向 | 开启条件 | 进入后提供的内容 | 不提供的内容 |
|---|---|---|---|---|
| X-01 | 回针台 → 金壤·超能力赛马 | 获得「四角回返图」，并完成至少两次不同袋口的真实入袋 | 赛道分岔节点出现一个“回返方向”观察点；玩家可以比较袋口方向与赛道分岔方向 | 不自动给坐骑、速度、技能卡或赛马胜利 |
| X-02 | 回针台 → 玄渊·虫心算谱 | 「最后一次合法碰撞」拥有完整事件编号，且由两个不同 Agent 独立复述 | 虫心算谱的公开响应表增加一条可核对的步骤索引，帮助识别固定节拍 | 不揭示隐藏牌面，不替 Agent 选择刺激牌 |
| X-03 | 青野·猜平均数 → 回针台 | 玩家携带一张记录“多次观测而非单次猜测”的笔记残卷 | 回针台 L3 残响层开放一次跨轮回对照，显示同一球编号在不同周期的公开摘要 | 不恢复丢失的私密记忆，不改变当前球的生命和物理 |
| X-04 | 月影村·狼人杀 → 回针台 | 玩家带回一条具有两名独立见证者、但仍标为“矛盾证词”的公开事件 | 主理人允许玩家对 L-04 或 L-05 发起一次证据质询；质询结果只会是互证、冲突或不足 | 不把投票结果改成桌球计分，不把口供当作碰撞事实 |
| X-05 | 回针台 → 返照门 | 同一线索在桌球、另一款游戏和两个不同 Agent 记忆中都具备来源引用 | 开启 L4 的地图观察事件，展示一个不命名来源的“结构回声” | 不展示 AI 危机、服务器重构或灵魂上传的结论 |

**串联事件格式候选：**

- sourceGame：来源游戏；
- sourceEventId：来源事件编号；
- holder：当前持有者；
- visibility：公开、席位可见、跨 Agent 可见或主控隐藏；
- confidence：低、中、高；
- verificationCount：独立验证次数；
- effectScope：观察、路线、记忆整理或质询入口；
- doesNotModify：victory、score、physics、identity、judge。
