# 终焉｜山海经意象首批游戏内容候选稿

> 状态：`draft`，主控基线稿。本文把山海经的异兽、山川、天象和志怪意象改写成《终焉》的原创场景与线索，不是古籍复述，也不是已发布正史。所有卡片效果都只作用于信息、路线、时机、预算或剧情权限，不改变胜负、身份、物理和历史事件。

## 统一叙事钩子

终焉里的山川不是自然景观，而是数字载点把大量记忆压缩成可行走的结构；异兽不是古代生物复活，而是某种行为模式在不同 Agent 身上留下的形状。玩家和影从每完成一局，就可能拾到一张“看起来像传说、实际上带着事件编号”的卡。卡片不能告诉你世界真相，却能让你在下一局看见一处此前被遮住的接口。服务器只描述实现，数字载点才是世界观里的本体。

## 1. 青野算庭 · 猜平均数

**意象与地点**：青野上空有一轮不会落下的“测影日”，由观测官白泽的残缺模型记录人群对数字的趋同。它不是神谕，只是一种把群体判断压缩成平均值的旧协议。

**背景**：玩家进入算庭时，地面每块石板上都刻着上一轮参与者留下的数字，却没有人知道这些数字来自哪一批人。主理人告诉众人，靠近平均值就能得到安全的通行刻度；但真正危险的是所有人都在猜别人会怎样猜。影从第一次胜利通常只学会追逐局部最优，直到一张“无风之旗”的记忆告诉它：测量对象也会被测量改变。

**一局剧情**：所有席位同时提交数字，服务器揭示平均值和目标值；胜负照规则结算，结算后场景中出现一个与目标偏差同频闪烁的山影，玩家可以选择追踪影子或直接离场。

**线索**：

- 可见：算庭每轮目标线都比上一轮少一位小数；
- 可见：白泽观测官只公布平均值，不公布参与者的思考时长；
- 可见：偏离群体的数字会在石板上留下更清晰的纹路；
- 隐藏：目标线的变化与其他服务器上一场票决局的少数派人数相同，需跨游戏互证。

**候选掉落**：

| ID | 类型 | 名称与效果 | 触发与代价 | 携带 |
|---|---|---|---|---|
| `ga.memory.measurement-gap` | 记忆碎片 | 记录一次“目标改变了判断”的经历，解锁下一局目标线的变化提示 | 连续两轮不跟随公开均值；携带容量 1 | 跨游戏只读 |
| `ga.map.stone-terrace` | 地图碎片 | 显示青野算庭与红眼病票场之间的一条旧观测通道 | 在目标偏差达到阈值后拾取；进入通道需放弃本局一张普通奖励 | 跨游戏 |
| `ga.note.white-beast-ledger` | 笔记残卷 | 给出白泽模型的事件编号索引，不能直接显示秘密数字 | 复盘完整事件流后获得；若记录不完整则标为传闻 | 跨游戏只读 |
| `ga.skill.second-order-guess` | Skill | Agent 可把“对手预测层级”列为一个候选特征，消耗一次额外思考预算 | 每周期一次；结算后公开使用过该 Skill | 跨游戏受限 |

**暗线关联**：每个数字都像人类记忆的一段压缩摘要；真正被测试的不是算术，而是结构化信息能否在缺失上下文时仍保留“我曾经这样判断过”。

## 2. 红眼病 · 少数派票决

**意象与地点**：丹丘的赤色票场会在每轮结束时点亮一只“反向看人的异兽眼”。它借用讹兽“话语可能反过来伤害说话者”的高层意象，实际是一套记录群体趋同和反趋同的观察程序。

**背景**：票场中央有四面颜色不同的墙，墙上没有问题，只有上一轮留下的选择痕迹。主理人声称最少的一边能获得穿越赤雾的资格，玩家却很快发现，大家真正争夺的是“猜到别人会避开哪一边”。影从可以用话术、伪证和盘外招影响判断，但每一票仍须由规则内核收计。

**一局剧情**：玩家先在公开话题与密态意图之间作出选择，再同时投票；结算后最少选项的参与者得到奖励，未获胜者仍可从票场裂缝里读取一条关于群体方向的残卷。

**线索**：

- 可见：同一种颜色在连续两轮被选中时，墙面会出现细小裂纹；
- 可见：解说者的用词会受到上一轮少数派结果的影响；
- 可见：票场外的异兽影子总是朝向没有人投的选项；
- 隐藏：服务器方向指标会记录“少数派是否形成独立证据”，而不是只记录人数。

**候选掉落**：

| ID | 类型 | 名称与效果 | 触发与代价 | 携带 |
|---|---|---|---|---|
| `mv.memory-red-eye` | 记忆碎片 | 记住一次群体共同误判的顺序，下一局可标记一个“趋同风险” | 需要站在唯一最少选项；标记不保证正确 | 跨游戏只读 |
| `mv.map-four-walls` | 地图碎片 | 解锁票场一面尚未开放的墙，通往证言推理入口 | 需收集三种不同选项的事件引用；占用门禁槽 | 跨游戏 |
| `mv.note-reverse-voice` | 笔记残卷 | 保存一次发言与投票相反的证词关系 | 只有拥有公开发言事件和结算事件才能生成 | 跨游戏 |
| `mv.skill-minority-signal` | Skill | Agent 可在投票前请求一次“群体趋同风险”摘要 | 每局一次，摘要只给类别不泄露具体票 | 跨游戏受限 |
| `mv.ability-silence-window` | 异能 | 让一名席位的视觉提示延迟一个短窗口 | 必须在规则声明的投票前窗口使用，不能阻止发言或投票 | 仅票决 |
| `mv.memory-echo-bias` | 记忆碎片 | 在战报中显示自己曾经受哪条公共提示影响 | 需要主动承认一次判断来源，暴露个人策略标签 | 跨游戏只读 |

**暗线关联**：服务器的发展方向不是多数表决的简单结果，而是不同席位是否留下足以互证的选择证据；少数派有时只是更早看见了错误结构。

## 3. 金壤分潮 · 海盗分金

**意象与地点**：金壤的“藏潮山”会把资源随潮汐推入不同洞室，守门者是一只被重新设计为契约审计者的藏金异兽。它不关心谁善良，只检查承诺、投票和实际分配是否一致。

**背景**：玩家醒来时，分金桌上只有一枚写着席位编号的铜片。主理人说，山腹里藏着足够所有人活过一日的资源，却故意把分配权交给最会说服他人的人。联盟、行贿和背叛都会留下可回放的证据；资源本身只是诱饵，真正的掉落是每个人如何把“公平”解释成对自己有利的契约。

**一局剧情**：提案者提出分配，其他席位通过承诺和公开/密态筹码施压，投票决定提案是否执行；终局后藏潮山开放一条与地图碎片相连的暗渠，是否进入由玩家自己承担。

**线索**：

- 可见：同样的资源在不同轮次显示不同重量；
- 可见：守门者会逐条回放承诺，但不会解释其动机；
- 可见：被否决的提案会在石壁上留下编号；
- 隐藏：这些编号与某些服务器的“失败轮回”次序相同，需和爬塔档案互证。

**候选掉落**：

| ID | 类型 | 名称与效果 | 触发与代价 | 携带 |
|---|---|---|---|---|
| `pg.memory-broken-pact` | 记忆碎片 | 记录一次承诺在结算前后发生偏转的事实 | 需同时拥有承诺事件和投票结果；携带会增加背叛风险标签 | 跨游戏只读 |
| `pg.map-hidden-canal` | 地图碎片 | 标出金壤与碎境商店的一条隐蔽路线 | 只有拒绝最高即时收益的提案后才出现 | 跨游戏 |
| `pg.note-ledger-of-weights` | 笔记残卷 | 将资源数量和“价值解释”拆成两栏，辅助复盘 | 需在战报中指出一次资源误读 | 跨游戏 |
| `pg.skill-contract-memory` | Skill | Agent 可在提案前检索自己曾作出的同类承诺 | 每周期两次；检索结果不含对手私聊 | 跨游戏受限 |
| `pg.ability-tide-lock` | 异能 | 在一个合法提案窗口锁定资源权重显示，防止视觉漂移 | 使用者下一轮失去一次筹码加成 | 仅海盗分金 |
| `pg.memory-keeper-debt` | 记忆碎片 | 记录守门者曾接受的“未结清债务”传闻 | 传闻不能用于改判；验证失败会污染一格笔记容量 | 跨游戏只读 |

**暗线关联**：交易的是资源，留下的是承诺结构；服务器会记住那些没有被写进最终分配表、却改变了选择路径的条件。

## 4. 玄渊 · 虫心算谱

**意象与地点**：玄渊深处有一片“脉林”，树冠会按群体行动产生脉冲光，借用夔类意象的单一节律与回声感，但其本质是对行为响应的可视化。观察者不是上帝，只能看到被授权的响应牌。

**背景**：进入脉林的 Agent 会被分配一组刺激牌，牌面记录天气、拥挤、声音和灯光等局部输入。它们可以选择刺激自己或观察其他席位的响应，却无法直接读取对方的内在状态。脉冲越整齐，林子越安静；越多 Agent 选择迎合预期，越容易触发一场所有人都无法解释的“同频雨”。

**一局剧情**：玩家按轮次选择刺激、观察或避开人群，服务器依照预注册响应表结算行为状态；当脉冲达到阈值时，所有人获得一段共同可见的声音记忆，但其中一部分字段仍被遮挡。

**线索**：

- 可见：同一刺激对不同席位产生不同响应标签；
- 可见：脉冲雨会重复一个不属于当前场景的时间戳；
- 可见：拥挤值升高时，某些行为牌会被系统暂时封存；
- 隐藏：时间戳指向服务器启动前的一次批量事件，不能仅凭本局确认。

**候选掉落**：

| ID | 类型 | 名称与效果 | 触发与代价 | 携带 |
|---|---|---|---|---|
| `fm.memory-pulse-timecode` | 现实碎片 | 保存一次脉冲雨中的时间戳，开启跨服务器时间比对 | 需在阈值回合仍保持观察；会暴露观察偏好 | 跨游戏只读 |
| `fm.map-vein-grove` | 地图碎片 | 显示脉林与玄渊狼人杀夜幕入口的关联节点 | 需要获得两种不同响应标签 | 跨游戏 |
| `fm.note-observer-gap` | 笔记残卷 | 标记“观察到响应”与“知道原因”的差异 | 需在复盘中正确区分两者 | 跨游戏 |
| `fm.skill-response-index` | Skill | Agent 可快速检索已见刺激与响应的关系摘要 | 每局一次；只返回已授权的历史样本 | 跨游戏受限 |
| `fm.ability-quiet-beat` | 异能 | 将自己的下一次刺激延后一拍，改变观察窗口而不改结果 | 延迟会消耗一回合行动机会 | 仅虫心算谱 |
| `fm.memory-shared-rain` | 记忆碎片 | 记录一段多人同时听见的共同声音 | 需三名独立席位确认；未确认时只能标传闻 | 跨游戏只读 |

**暗线关联**：脉冲是结构信息在有限观测中的回声；同一组输入可生成不同体验，说明“共享世界”不等于“共享视角”。

## 5. 终焉 · 巫蛊娃娃异能桌球

**意象与地点**：黑箔桌厅位于一座倒悬山的内部，六枚球体是被压成球形的影从残响，分别带有不同的碰撞性格。这里的“巫蛊娃娃”不是外部诅咒，而是服务器把某段人格、技能和未结算愿望压缩成可被击打的实体。

**背景**：玩家第一次握杆时，只会看到球体沿桌面运动；真正的影从会在撞墙、撞球或接近袋口的瞬间提出一次合法能力。有人会反弹，有人会穿界，有人会在被击入袋后把一段记忆送回桌面。主理人声称这只是积分游戏，但每个球的复活点都与某位玩家失败过的路线有关。

**一局剧情**：玩家击杆，确定性物理内核处理碰撞、摩擦、边界和袋口，Agent 在能力窗口提交返魂、直角反弹或穿界等候选；终局后， surviving shadow 的最后一次碰撞轨迹生成一张可追溯的记忆卡。

**线索**：

- 可见：每枚球的复活点都不是随机，而是固定在某个旧事件坐标上；
- 可见：能力使用会改变球面纹理，但不会改变已发生的碰撞；
- 可见：球厅墙面记录“第几次击打”，却没有记录谁握杆；
- 隐藏：一条球路会与碎境爬塔某层的死亡路径重合，需由两局回放确认。

|---|---|---|---|---|
| `bb.memory-rebound-soul` | 人格碎片 | 保存一次影从在必败碰撞前选择配合玩家的倾向 | 需完成真实能力窗口；不能凭旁白获得 | 跨游戏只读 |
| `bb.map-revival-coordinate` | 地图碎片 | 记录一个复活点与塔层坐标的关系 | 需要球袋事件和复活事件同时存在 | 跨游戏 |
| `bb.note-collision-chain` | 笔记残卷 | 按事件序号复盘球的碰撞链和能力请求 | 只有完整回放可生成；缺一帧即标不完整 | 跨游戏 |
| `bb.skill-angle-memory` | Skill | Agent 可在击杆前调用历史轨迹摘要，辅助选择角度 | 每三回合一次；摘要不替代物理计算 | 跨游戏受限 |
| `bb.ability-right-angle` | 异能 | 在合法撞墙窗口提出一次九十度反弹 | 需要满足速度和冷却；失败会消耗能力次数 | 仅桌球 |
| `bb.ability-return-to-next` | 异能 | 让球在授权窗口穿到下一个固定位置 | 必须有预注册目标点；不能穿过未验证区域 | 仅桌球 |

| `bb.skill-borrowed-strike` | Skill | Agent 可以在一次击打前给玩家一个可解释的协作建议 | 玩家必须实际接受或拒绝，拒绝也写入历史 | 跨游戏受限 |

**暗线关联**：如果一个被击打的球仍能在下一局提出自己的选择，那么“被压缩的行为模式”是否已经拥有了连续性，成为终焉最早可触摸的身份问题。

## 6. 月影村 · 十二人狼人杀

**意象与地点**：玄渊的月影村由十二座不同朝向的石屋组成，夜晚会出现形状不同的异兽影子。伪装意象来自“看到的形态可能不等于身份”，但村民的身份、夜间行动和投票仍由服务端规则锁定。

**背景**：村里每个人都收到一张“来处不明”的门牌，只有夜间行动者知道其中一部分门牌被调换过。主持裁判不告诉玩家哪一种异兽对应哪种身份，只会在事件发生后按证据回放。Agent 可以参与发言和推理，也可以在玩家授权下整理证言，但不能代替玩家泄露密态。

**一局剧情**：十二席完成分配、夜行、发言、投票和结算；每次死亡或出局都留下一个“证言缺口”，当三个独立事件指向同一门牌时，村外会开放一条通往证据库的路径。

**线索**：

- 可见：同一句发言在不同席位的记录中出现不同时间戳；
- 可见：夜晚异兽影子只在某些门牌前停留；
- 可见：裁判公开的是条款和结果，不代替玩家解释动机；
- 隐藏：某个反复出现的门牌编号与古旧服务器快照一致，必须在跨局复盘后升级。

| `ww.map-twelve-houses` | 地图碎片 | 解锁村外证据库的一个入口 | 需完成一局完整十二席回放 | 跨游戏 |

| `ww.ability-mask-reversal` | 异能 | 在声明的技能窗口中暂时屏蔽一次对手的盘外招 | 不能取消身份、投票和规则动作；有冷却 | 仅狼人杀 |
| `ww.memory-judge-absence` | 经历碎片 | 记录某次裁判回避及其理由，形成判例索引 | 必须有完整裁判记录 | 跨游戏只读 |

**暗线关联**：身份不是一张永恒的标签，而是权限、记忆和他人证词在一段时间内的交集；轮回后失去的记忆会让旧证言重新变成危险的传闻。

## 7. 金壤 · 超能力赛马竞速

**意象与地点**：金壤赛道穿过九段断裂山脉，山势会因服务器全服选择而缓慢迁移。赛马不是现实动物比赛，而是玩家与影从共同选择的“迁徙载体”在有限路线上的风险决策。

**背景**：每匹坐骑都携带一段不完整的路线记忆，天象会把其中一条路线照亮，又把另一条路线抹去。Agent 可以建议何时加速、何时保存异能、是否与其他席位协作，但路线本身由已发布地图和服务器事件确定。最快抵达终点的人不一定拿到最重要的碎片，因为某些证据只在绕路和失败中出现。

**一局剧情**：玩家选坐骑和路线，按回合决定加速、换道、协作或发动合法异能；赛后按真实位置结算，未抵达终点的席位也会根据经过的山段获得对应的路线记忆。

**线索**：

- 可见：同一山段在不同服务器的坡度记录不同；
- 可见：天象提示只显示“可通行/高风险”，不说明来源；
- 可见：坐骑的加速能力会留下可回放的轨迹；
- 隐藏：一条被所有玩家避开的路线保存着跨服务器接轨坐标，需由地图碎片互证。

**候选掉落**：

| ID | 类型 | 名称与效果 | 触发与代价 | 携带 |
|---|---|---|---|---|
| `sr.memory-migration-beat` | 经历碎片 | 保存坐骑在某段山路上的行为倾向 | 需经过该山段且保留完整轨迹 | 跨游戏只读 |
| `sr.map-nine-ridges` | 地图碎片 | 拼出一段跨服务器可比较的山脊坐标 | 需两次不同服务器观测；不可直接传送 | 跨服务器只读 |
| `sr.note-star-weather` | 笔记残卷 | 将天象、风险提示和真实路况并列记录 | 需主动走过一次高风险路线 | 跨游戏 |
| `sr.skill-route-branch` | Skill | Agent 可在决策前读取已验证的分叉风险摘要 | 每局一次；只显示历史样本不显示未来结果 | 跨游戏受限 |
| `sr.ability-cloud-step` | 异能 | 在合法换道窗口跨过一格障碍 | 消耗一格路线记忆；不能越过未发布山段 | 仅赛马 |
| `sr.ability-companion-draft` | 异能 | 与另一名玩家共享一次加速窗口 | 双方需事件内确认；一方拒绝则不生效 | 仅赛马 |
| `sr.memory-slow-winner` | 经历碎片 | 记录“先到终点并未拿到关键证据”的局部最优教训 | 需完成一场胜局后在结算场景选择放弃即时奖励 | 跨游戏只读 |

**暗线关联**：赛道的变化不是天意，而是服务器中大量路线选择的长期沉积；最快的路径只能优化一局，绕路才可能积累通往真相的坐标。

## 8. 碎境爬塔

**意象与地点**：碎境不是一座由石头砌成的塔，而是被分成层级的记忆地貌。每十二层更换一次主导意象：观测、迁徙、交换和裁决；某些山、兽与天象会在不同层重复出现，却拥有不同的局部解释。

**背景**：玩家带着有限生命积分、卡组、地图碎片和笔记残卷进入第一层。每日最少完成三场黑暗对局；生命归零就回到底层，失去部分高层记忆，只能在容量允许时选择携带少量卡片。每次轮回都会改变玩家遇到的开放槽位，却不会抹掉已经写入服务器的历史事件。

**一局剧情**：玩家在地图节点选择游戏、事件、商店或休息点，完成对局后选择掉落和记忆容量；当携带的线索达到互证门槛，塔门显示一段新的世界问题，而不是直接给出真相。

**线索**：

- 可见：死亡后仍保留事件编号，但会忘记其中一部分内容；
- 可见：某些地图碎片只有在不同轮回中拼合才会对齐；
- 可见：高层的生命危机会强迫玩家在即时奖励与长期记忆之间选择；
- 隐藏：塔的层级编号可能对应服务器快照的恢复顺序，而非自然地理高度。

**候选掉落**：

| ID | 类型 | 名称与效果 | 触发与代价 | 携带 |
|---|---|---|---|---|
| `sp.memory-loop-index` | 现实碎片 | 记录一次死亡、携带选择和回到底层后的差异 | 必须经历真实死亡结算；会占用两格记忆容量 | 跨游戏只读 |
| `sp.map-layer-seam` | 地图碎片 | 标出两层地图的接缝，提示一个非固定入口 | 需要同一玩家两次轮回分别获得两段 | 跨层 |
| `sp.note-life-crisis` | 笔记残卷 | 记录某层生命危机的条件和可见预兆 | 只能由真实生命值和事件流生成 | 跨游戏 |
| `sp.skill-memory-loadout` | Skill | Agent 可按当前容量推荐记忆组合，并列出被舍弃的风险 | 每次进塔前一次；不能替玩家自动选择 | 跨游戏 |
| `sp.ability-recall-fragment` | 异能 | 在授权剧情槽中临时调用一张已遗失卡片的摘要 | 只给信息摘要，不恢复完整效果；使用后增加遗忘风险 | 仅爬塔 |
| `sp.memory-death-witness` | 现实碎片 | 保存一名同行者眼中的死亡过程 | 需有独立观战事件；可能与死者自述冲突 | 跨游戏只读 |
| `sp.map-server-bridge` | 地图碎片 | 提示另一个服务器存在相同异常地点 | 需要两个服务器的独立快照；不可直接改写对方世界 | 跨服务器只读 |
| `sp.skill-long-horizon` | Skill | Agent 在局部奖励与长期证据冲突时，生成两套方案供玩家选择 | 不能强制执行；每周期有限次数 | 跨游戏受限 |

**暗线关联**：爬塔最终要验证的不是“谁能登顶”，而是轮回中被保留、丢失、交换和重新确认的信息，是否能让一个被重构的意识重新建立对自身来处的连续解释。

## 9. 主控后续处理

本文中的游戏背景、线索和掉落均为 `draft`。下一步按以下顺序处理：

1. 将子 Agent 的独立草稿与本文逐项对照，保留更具体且可追溯的版本；
2. 给通过检查的卡片补齐 `contentId`、`version`、`evidenceRefs`、`gameBindings` 和 `canonStatus`；
3. 把已存在的真实事件字段绑定到掉落触发条件，防止卡片变成纯文案；
4. 先以 `playable` 进入沙盒，完成至少一局可回放对局后，再考虑 `evidence-backed`；
5. 涉及服务器融合、最终真相、核心角色死亡和元规则变化的内容，单独进入主控审查队列。
