# 《十日牌局》30 秒宣传 PV v1

- 片名：**《十日牌局：回响》**
- 成片：30 秒，16:9，高规格游戏 CG 过场（CG cinematic trailer），不是真人感短视频
- 生成拆分：2 × 15 秒 Seedance 2.5，TAIL_RELAY
- 目标：3 秒建立“十日终焉”的压迫感，15 秒内看懂四种智斗，30 秒后记住“回响”。
- 原创边界：保留十日轮回、终焉、回响的设定骨架；台词、动作、机制文案全部为《十日牌局》原创，不使用原著原句。

## 1. 故事脊柱

世界每十日重启一次。旅人进入牌局之间，以隐藏信息、平均数、谈判和资源取舍换取下一日；当终焉吞没所有大陆，真正留下来的不是胜负，而是仍在记得彼此的回响。

情绪弧线：窒息 → 猜疑 → 清醒 → 追杀 → 终焉 → 新生。

视觉锚点：十枚金色太阳、墨绿牌桌、旅人右手红绳、掌心金色碎片、四大陆的四种颜色，以及只出现一次的终焉使者。

CG 美术基准：沿用现有卡牌人物的脸型、服装、饰物、材质和色彩；角色以可被镜头近距离识别的游戏 CG 模型呈现，场景使用 PBR 材质、体积雾、真实金属反射和克制的粒子，不做赛博霓虹或廉价手游特效。

## 5. Seedance 2.5 提示词

### Clip A｜0–15 秒｜入局与智斗

专业分镜模式，横屏 16:9，15 秒，高规格游戏 CG 过场，东方暗黑奇幻，沿用现有卡牌人物的建模与材质语言，PBR 金属、布料、玉石和毛发，电影级体积雾与真实光影，墨韵星云与赌局金箔统一视觉。@旅人是黑金短斗篷、右手红绳、掌心金色碎片的背影型主角；@讹兽是火光中一闪的人面兔身骗徒；@璇玑是操控悬浮算珠的机关术士少女；@青囊与@阿九只作为丹丘红雾中的对手剪影；@烛阴是能以睁眼转昼、闭眼转夜的金壤庄家；@牌局之间是墨绿绒面牌桌、黄铜灯、六把椅子。场景顺序清楚，动作有因果。

0–1.5 秒黑场裂开，十枚金色太阳像十枚瞳孔同时睁开，焦黑天空被牌面纹路划开。1.5–3 秒@旅人触碰竖起的巨牌门，身后地面开裂，尘土被门吸走。3–4.8 秒进入@牌局之间，空椅子自行后移，桌心碎片点亮。4.8–6.6 秒玄渊夜村火把环住六个模糊身份，@讹兽压住一张牌，半张脸在火光中闪过。6.6–8.6 秒青野算庭，@璇玑拨动悬浮算珠，算珠形成三层旋转环。8.6–10.4 秒近景，@旅人先准备提交 50，观察五只迟疑的手后改成 17，不出现可读 UI 字幕。10.4–12.4 秒丹丘红雾，@青囊推来满茶，@阿九狐火掠过杯沿，旅人不接茶，红雾合拢。12.4–15 秒金壤琥珀河，@烛阴睁眼，金河由夜转昼，他推出最后筹码；@旅人用掌心碎片压住筹码拒绝加注。最后一帧定格在碎片高光，供下一段接力。

旁白后期录制：“第十日，太阳会熄灭。想活下去，先看懂规则。你以为你在猜答案，其实答案在猜你。”角色声音只短叠：“我说真话的时候，你信吗？”“所有人的答案，再往下算一层。”“筹码即时间。”镜头从慢推进入局，随后快速切换；木牌、算珠、茶盏、筹码和心跳作为切点。保持红绳、黑金袖口、金色碎片连续。不要字幕、水印、画面文字、现代 UI、霓虹赛博朋克、廉价游戏 CG、随机新增角色、变脸、多余手指、太阳数量漂移、动作失去因果。

### Clip B｜15–30 秒｜生存与终焉

专业分镜模式，横屏 16:9，15 秒，必须从上一段真实尾帧的金色碎片高光无缝接入，保持@旅人的黑金短斗篷、右手红绳、掌心碎片、光线方向和向右运动方向一致。仍为高规格游戏 CG 过场、东方暗黑奇幻、PBR 材质、电影级体积光、卡牌人物的高辨识度造型；终焉表现为世界折回一张牌，不是普通爆炸。

0–2.2 秒延续尾帧，@旅人把碎片压进裂桥边缘，桥面多撑一秒后向右冲出，金壤天空塌下一块。2.2–4.4 秒玄渊黑雾，@白泽抬眼看见移动火点，停步不攻击，因为火点方向暴露追兵。4.4–6.6 秒@旅人沿悬空石阶向右奔跑，身后四大陆颜色像碎片一样崩落；他回头看见同伴被雾吞没但继续前进。6.6–8.8 秒@终焉使者从十日阴影降下，赤金日冕连射，攻击掌心碎片；@旅人松手半秒躲过，再在碎片坠落前接住，爆裂白光充满画面。8.8–10.8 秒声音抽空，雾、算珠、红灯、金河全部静止，十枚太阳依次熄灭，世界沿牌面纹路折叠为星尘。10.8–13.2 秒黑暗中@旅人摊开手，碎片逆着星尘飞向新日，内部短暂闪过@白泽、@讹兽、@璇玑、@烛阴的眼睛。13.2–15 秒新日从牌桌后升起，@旅人与影从并肩站在重新开启的牌门前，镜头缓慢后拉。后期最后一句：“我听到了生生不息的回响。”末尾叠片名“十日牌局”。

动作因果必须清楚：碎片支桥、停步识破、松手躲避、接回记忆、世界折牌、新日升起。不要字幕、水印、画面文字、现代 UI、额外主角、终焉使者长时间站桩、无因果飞行、服装漂移、脸部变形、肢体穿模、城市爆炸式毁灭、过度粒子遮挡主体。

## 6. 后期与成片检查

- 先剪出 A01–A08、B01–B07 的可用动作段，再做节奏，不强求每个生成片段完整保留。

- 台词全部后期录音，Seedance 只负责环境声和动作声氛围。
- 片尾台词从 28.2 秒开始，画面保持新日和牌门，避免密集信息。
- 片名和 Logo 由后期或网页覆盖，避免模型生成乱码文字。
