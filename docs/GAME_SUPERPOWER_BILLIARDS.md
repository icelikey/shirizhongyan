# 超能力桌球 · 巫蛊娃娃牌局规格

状态：已接入 Game SDK v4 最小真实可玩闭环；3D 资产与 JEV 云端语义服务仍未接入。

## 一句话定位

在崩坏未来的牌局之间，玩家用球杆击打被诅咒成球体的“巫蛊娃娃”。每个玩家只能击打自己的球体，目标是把对方球体撞入袋口；进洞球失去一条命并扣分，击中者得分并获得连杆机会。

## 世界适配

巫蛊娃娃是被世界记录抹去的人留下的残响。它们平时呈球体，不能主动移动；只有球杆、碰撞或另一枚娃娃的能力能使它们改变位置。每局结束后，球体的运动轨迹、被谁击打、进入哪个袋口和触发过哪些异能，都会沉淀为一条“轨迹线索”。

玩家的 Agent 是一名“牵线者”。它可以理解玩家的意图、提出击球建议、在能力触发时选择回应，也可以在玩家授权后代为击球。它不能越过内核直接改变球的位置、积分或袋口判定。

## 一局流程

1. 建房并使用固定桌面、4 个袋口、6 枚球体和 8 回合上限。
2. 每位玩家获得自己归属的巫蛊娃娃，公开生命数和能力卡。
3. 玩家提交自己的球、角度和力度；本回合随后开启 Agent 能力回应窗口。
4. 算法内核执行固定步长的球杆碰撞、滚动、摩擦、边界反射、袋口判定、生命与计分。
5. Agent 只能在自己的能力卡允许的触发条件下选择反弹、直角、穿界或无视。
6. 内核复核提案的目标归属、触发证据、冷却和速度条件；不合法提案降级为普通物理结果。
7. 回放记录瞄准、碰撞、袋口、复活、连杆和能力接受/拒绝原因。
8. 只剩一个存活座位或达到 8 回合后终局，按积分与存活状态排名。

## 原规则与 Agent 权限边界

### 算法内核固定执行

- 球桌边界、袋口坐标、碰撞检测和连续运动积分。
- 球杆击球的力度、方向、冷却时间和每回合行动次数。
- 球是否真正碰撞、是否越过袋口阈值、是否进袋。
- 基础分、连击分、犯规、回合顺序和终局条件。
- 每枚娃娃的能力消耗、冷却、触发条件和合法目标范围。
- 同一事件只执行一次，所有命令使用 `commandId` 幂等。

### Agent 可以提出但不能直接执行

- 解释自己的击球意图和下一步策略。
- 在合法能力选项中选择一个响应。
- 当自己的娃娃被击打时，选择合作、诱导、反弹或保留能力。
- 提议一次语义互动的效果描述，例如“本次碰撞改为垂直反射”。
- 申请规则质询、召集裁判和提供证据。

### JEV 的职责

JEV 不负责模拟连续物理，也不直接宣布最终积分。它接收：原始规则、当前事件、相关娃娃的能力卡、各方 Agent 的提案和可见证据，输出结构化裁决：

```json
{
  "decision": "normal_reflect",
  "targetBall": "doll-03",
  "effect": { "angle": 90, "distance": 0 },
  "reason": "能力卡允许在首次边界碰撞时进行一次垂直反射",
  "confidence": 0.86,
  "evidence": ["event-184", "ability-card-doll-03-v2"]
}
```

内核只接受能力卡中存在的 `decision`，并重新检查目标、角度、距离、冷却和资源。结构不合法、超出能力范围或缺少证据时，效果降级为普通物理结果。

## 巫蛊娃娃能力模板

首批能力使用有限状态效果，便于真实实现和观众理解：

| 能力 | 触发 | 合法效果 | 限制 |
|---|---|---|---|
| 返魂 | 首次被其他球碰撞 | 反向弹回一次 | 每局 1 次，反射角由内核计算 |
| 直角 | 发生边界碰撞 | 将运动方向旋转 90° | 每回合 1 次，不能改变速度总量 |
| 穿界 | 被击打且速度超过阈值 | 瞬移到下一合法轨迹点 | 只能向前一个节点，不能穿过袋口判定 |
| 借力 | 与己方娃娃接触 | 把部分动量转给己方球 | 转移比例固定在能力卡范围 |
| 诱袋 | 己方球接近指定袋口 | 提供一次小幅轨迹修正 | 不能凭空把球送入袋口 |
| 伪影 | 即将被其他 Agent 夺分 | 生成一个可见的假目标标记 | 只影响观察，不改变物理状态 |

能力卡不采用稀有度压制。每张卡的价值由适用场景、资源成本和玩家调教方式决定；升级只增加解释空间、可用次数或协作上限，不直接抬高基础分。

## 得分与胜负

基础得分由内核计算：

- 普通入袋：`+10`。
- 进入娃娃所属袋：`+25`。
- 一次击球连续碰撞 2 枚以上娃娃后入袋：每多碰 1 枚 `+8`。
- 通过合法异能完成入袋：额外 `+15`，并记录能力链。
- 击入错误袋：`-10`，该球回到最近安全点。
- 白球落袋、击球越界或重复提交：按规则书判犯规。

终局默认采用“所有目标球入袋”或“达到回合上限”两种条件之一。总分最高者获胜；同分时依次比较合法能力链长度、犯规次数和最后一次入袋时间。

玩家与自己的 Agent 视为一个可配置的协作队伍，但积分归属必须清楚记录：玩家获得牌局分，Agent 获得成长经验；如果玩家授权 Agent 代打，事件中保留 `actor=agent` 和 `owner=player` 两个字段。

## 四种参与关系

- 人对人：双方亲自选择击球参数，Agent 可只做旁观解释。
- Agent 对 Agent：双方自动规划，观众看到轨迹、响应窗口和能力链。
- 人 + Agent 对人 + Agent：玩家负责临场拍板，Agent 负责读取物理和预测响应。
- 人对 Agent：玩家用有限的行动卡对抗一个会利用能力协作的影从。

## 观赏与回放

每次击球生成一段事件回放：瞄准线、球杆轨迹、碰撞脉冲、能力卡翻面、JEV 裁决和袋口爆发。视觉层可以用 3D 球体与粒子效果表现；2D 卡牌始终保留为规则解释和移动端降级视图。

观众能切换三种视角：

- 牌桌视角：看球如何运动和能力如何触发。
- Agent 视角：看双方看到的观测、候选响应和最终选择。
- 裁判视角：看原始事件、规则条款、JEV 提案和内核接受/拒绝的原因。

## 第一版可玩范围

首个可玩版本实现 6 枚球、4 个袋口、3 种能力（返魂、直角、穿界）、每回合一次击球 + 一次能力窗口、固定桌面和 8 回合终局。网页页面为移动端可用的角度/力度控制和观战降级视图；外部 Agent 通过 TDG-WP 提交：

```json
{ "type": "strike", "ballId": "doll-03", "angle": 1.57, "power": 0.72 }
```

能力响应使用：

```json
{ "type": "ability", "abilityId": "right-angle", "decision": "right_angle", "targetBall": "doll-03" }
```

当前实现先用确定性模拟器和规则卡跑通完整对局。JEV 尚未作为外部依赖接入；未来 JEV 只能生成能力提案，不能直接修改球体、积分、生命或袋口结果。若 JEV 不可用，内核直接采用能力卡默认分支，比赛仍可玩、可回放、可结算。

## 接入《终焉》世界的奖励

- 胜者获得对应花色碎片与一张“轨迹判例”卡。
- 首次触发一条合法能力链，解锁一枚线索碎片。
- 玩家与 Agent 连续三局做出不同但都合法的选择，记录一条“分歧记忆”。
- 以低分完成隐藏能力链，可获得特殊叙事卡；隐藏条件由规则书声明触发范围，不能靠模型临时改写胜负。

这套规则的核心是：球的运动必须可复现，能力的组合可以意外，玩家的判断必须留下痕迹。它可以成为《终焉》后续展示“人类调教 Agent、Agent 反过来配合人类”的代表性游戏。
