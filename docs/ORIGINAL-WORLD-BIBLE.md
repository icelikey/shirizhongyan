# ORIGINAL WORLD BIBLE

> 状态：原创世界观边界基线
> 适用范围：长期产品母体“终焉”、黑客松切片及其后续游戏、叙事和运营内容
> 来源纪律：本文件只规定本项目原创世界；参考作品只提供结构性研究输入，不提供本项目的世界事实、专名、角色、台词、地点或剧情。

## 1. 世界观总原则

“终焉”是一个可持续扩展的智斗产品母体，不是对任何单一小说世界的复刻，也不是把若干小游戏包在同一层美术包装里。它的核心问题是：

> 当世界以有限周期反复收束，参与者只能看到局部事实，并能通过对局、记忆和规则质询改变未来时，谁有资格定义下一次结算？

产品母体由四个可复用层组成：

1. **世界层**：持续存在的终焉域、48 层塔、周期推进、记忆与判例。
2. **游戏层**：可替换的对抗规则；每个小游戏都是一次局部世界实验。
3. **智能体层**：真人、外部 Agent、内置影从和裁判共同参与，但权限不同。
4. **证据层**：事件流、公开投影、密态记录、能力使用记录和判例构成可回放的事实链。

任何新内容都必须先回答“它改变了哪条世界规则、谁看得见、何时生效、如何复盘”，再决定角色名、美术风格或叙事包装。

## 2. “终焉”作为长期产品母体

### 2.1 母体承诺

长期产品不是承诺一条固定小说主线，而是承诺一个能持续产生新局面的规则宇宙：

- 新增游戏可以成为一层、一个区域或一个周期的局部规则；
- 新增角色必须由可验证的行为倾向和能力接口定义；
- 新增叙事必须由已发生的对局事件、判例或周期结果触发；
- 新增世界规则必须有版本、适用范围、可质询性和回放方案；
- 玩家长期保留的是可验证的记忆、能力成长、收集和判例影响，而不是未经证实的“传说”。

“终焉”因此有两个时间尺度。对局内是有限倒计时和逐步揭示；产品长期是多个周期累积的规则演化。历史事件可以改变未来入口、能力池和叙事解释，但不能改写已经结算的事实。

### 2.2 黑客松切片

黑客松切片是母体的可演示纵截面，目标是在短时间内让观众看懂三件事：

1. 真人与 AI 在同一局中拥有不同信息和不同决策能力；
2. 能力只能改变信息、时机或资源路径，不能偷偷改写胜负函数；
3. 一次成功的规则质询可以形成未来可见的判例，但不回溯历史。

切片只需要一个清晰的主游戏、一个可复盘的事件流、一个短周期和一段可见的裁判过程。48 层塔、十个叙事周期和完整长期经济可以只展示入口、样例层和未来锁；它们不能被假装成已经全部实现。

切片的验收重点是“现场能否看懂因果链”，不是内容数量。演示文案应使用本项目自己的名词和例子，避免把参考作品的设定当作卖点。

## 3. 原创世界规则

### 3.1 终焉域

终焉域是由规则版本、参与者席位、可见性投影和结算边界共同定义的局部世界。它不是天然的地理地点，也不要求每局拥有固定地图。一个终焉域至少包含：

- 当前周期与剩余阶段；
- 参与者及其席位权限；
- 当前规则书版本；
- 对每个席位可见的公开信息与密态信息；
- 可使用的能力、资源和冷却；
- 事件流、结算结果和可提出的质询。

“进入”意味着接受该域的观察与结算协议；“离开”意味着本局已经结束或被合法中止。没有事件证据的传闻不能直接升级为世界事实。

### 3.2 十个叙事周期

十个叙事周期是母体的长线节拍，每个周期都必须有一个规则问题、一个信息问题和一个可验证的结果。周期不是对参考作品十日结构的复述，也不是简单把十天换成十章。

建议采用以下原创功能分工，名称可在后续文案中再定：

| 周期 | 叙事任务 | 机制验收 |
|---|---|---|
| 1 | 入域：建立席位、观察权限和第一条不可质询的基础规则 | 新玩家能完成一局并理解公开/密态边界 |
| 2 | 试探：让能力第一次改变信息获取成本 | 能力效果有日志、有代价 |
| 3 | 结盟：引入承诺、谈判和可验证的背叛 | 联盟结果不能只靠旁白宣布 |
| 4 | 误差：让假信息与真信息拥有相同表现形式 | 玩家能在结算后复盘误导来源 |
| 5 | 迭代：能力出现第一次可追踪演化 | 演化由使用记录和条件触发 |
| 6 | 争律：开放边缘条款质询 | 核心胜负条款仍受保护 |
| 7 | 分裂：同一事实产生不同席位投影 | 每种投影都能由权限重建 |
| 8 | 代价：让更强的信息或能力付出时间、资源或暴露风险 | 不存在无成本全知 |
| 9 | 审判：奇数裁判团处理争议并形成判例 | 参与者回避、票型和依据完整可查 |
| 10 | 收束：周期结算并留下下一周期可继承的状态 | 历史冻结，未来入口明确 |

这十个周期是结构模板，不是预写剧情。每次产品迭代可以替换局部游戏和角色，但不能跳过“信息变化—能力响应—裁判/结算—历史留痕”的因果链。

### 3.3 48 层塔

48 层塔是母体的空间化进度结构，分为四个 12 层位阶区。每层必须同时定义：

- 层号、位阶和进入条件；
- 主导花色或规则主题；
- 该层允许使用的游戏模板；
- 掉落、残章、能力或判例的来源；
- 一条可复现的失败原因；
- 对下一层形成的门禁影响。

塔的功能是让长期成长有方向，而不是把内容按楼层堆放。四个 12 层区可以分别承担“看见信息、管理信息、质询规则、创作规则”的递进，但每个区仍须由实际关卡验证，不得只靠标题宣称成长。

层门禁分为四类：公开完成条件、收集条件、曾成功质询的判例条件、被系统收录的原创规则条件。门禁不得依赖隐藏的人工判断；若玩家无法从记录中知道缺什么，世界观和产品引导都算失败。

## 4. 山海经意象的使用边界

山海经意象只作为原创设计的视觉和行为锚点。它可以帮助玩家快速感知“辨伪、观测、时间、迁徙、资源、威慑”等力量方向，但不自动带来古籍中的身份、神话关系、故事结局或权威。

允许：

- 重新设计异兽、山川、器物和天象的形态、功能与社会语境；
- 将意象映射为影从的行为偏好、能力代价和区域视觉语法；
- 用原创证据碎片解释某种现象如何成立；
- 在卡面和场景中保留“像某种古典意象”的联想。

禁止：

- 直接使用古籍或参考作品的原文、角色关系、台词、地点和具体事件；
- 让一个传统名称直接等于本项目的能力说明；
- 用“古籍记载”替代规则条款、事件证据或裁判依据；
- 让视觉生成结果反过来决定已经结算的世界事实。

每个意象进入产品前，都要有一张原创设计卡：新名称或明确授权的通用意象、行为倾向、能力边界、反制方式、信息可见性、首次出现周期和来源说明。

## 5. 信息不对称

信息不对称是终焉的基础张力，不是装饰性的“神秘感”。每个关键事实必须标注：

- 谁知道；
- 谁不知道；
- 谁可以验证；
- 什么时候公开；
- 公开后是否允许被能力扭曲；
- 结算后如何回放。

信息分成三类：

1. **公开事实**：所有席位可见，进入公共事件流。
2. **席位事实**：只向满足权限的席位投影；可以是手牌、意图类别、局部观察或裁判材料。
3. **系统事实**：用于结算和回放，不能被普通能力直接读取；在合法揭示节点才转为公开事实。

能力可以改变“看见什么、何时看见、需要付出什么”，但不能无记录地删除事实，不能伪造历史事件，不能越过权限读取系统事实。观战视角可以更完整，但必须明确标记其全知范围，避免把观战信息误认成玩家当时拥有的信息。

## 6. 能力演化

能力演化描述智能体如何从重复决策中形成稳定倾向。演化必须有事实来源：

- 使用次数、成功与失败；
- 在何种信息条件下使用；
- 支付了何种代价；
- 对局结果是否改变了未来选择；
- 是否经过周期或判例确认。

能力只能落在五类作用点：投影、思考时间、提交动作、揭示顺序、结算资源。能力可以强化、分叉、互相克制或产生反噬，但不能直接修改核心胜负、基础计分、历史日志和裁判回避规则。

每次演化至少写清：

- 触发条件；
- 新增效果；
- 新增代价；
- 对手可以观察到的迹象；
- 可反制手段；
- 版本和回放兼容策略。

“成长”不是角色卡上的形容词。没有事件记录、条件和代价的升级，只能算文案，不算世界事实。

## 7. 奇数裁判

奇数裁判是世界内部的争议处理协议。法定席位只能是 3、5 或 7，裁判团必须满足：

1. 裁判不属于当前争议的参与者；
2. 核心胜负与核心计分条款不可被普通质询；
3. 质询必须指出具体条款、事实证据和适用范围；
4. 每票都能记录裁判身份、依据和版本；
5. 多数结果形成判例，平票不可作为正常结果；
6. 判例只影响生效点之后的局面，不改判已经结算的历史。

裁判分为三种职责：纯规则计算、语义边界判断、争议仲裁。它们可以由算法、模型或其他 Agent 承担，但角色名称不能掩盖权限。裁判的判断必须能降级到结构化规则或启发式路径，避免网络、模型或文本生成失败时世界停摆。

判例不是“裁判说了算”的剧情工具。它必须包含条款版本、事实快照、投票构成、生效时间、影响范围和回放结果。任何新判例如果无法说明“从哪一局、哪条证据、哪次投票而来”，都不能进入正典。

## 8. 参考作品边界

《十日终焉》（校对全本）只作为结构研究材料。本项目可以研究并重新设计以下抽象机制：

- 封闭或受限空间中的高压对局；
- 有限周期带来的倒计时与重置压力；
- 记忆、信息或经验需要通过条件才能继承；
- 游戏结果既影响生存/资源，也影响后续叙事；
- 能力差异制造不对称，并由代价维持张力；
- 规则不是背景说明，而是角色必须理解、利用和承担后果的对象。

本项目不得复制或近似复现：

- 原作的世界名称、组织、角色、人物关系、地点、专有概念和台词；
- 原作的具体游戏、关卡、谜底、事件顺序、场面调度和剧情因果；
- 原作的叙述句式、标志性表达、设定解释方式和角色声音；
- 以“同一世界观衍生”“官方延伸”或相似表述对外宣传；
- 只换名词、保留角色功能和剧情骨架的伪原创内容。

每次引用参考作品进行设计评审时，只记录“结构机制—本项目改写—原创差异—验证方式”四项，不记录原文摘抄。若一个设计必须依靠读者认出原作才能成立，则它还没有完成原创化。

## 9. 世界观验收标准

### 9.1 文档验收

- 能明确区分母体规则、黑客松切片和未来设想；
- 每个新名词都有定义、权限、机制入口和禁止解释；
- 十个周期、48 层塔和能力演化之间有可追踪关系；
- 山海经意象不会被误读为既定神话事实；
- 参考边界在设计、宣传和资产制作中都可执行。

### 9.2 机制验收

- 一个新玩家能在短演示中理解公开信息、密态信息和揭示时点；
- 能力效果可由事件流复盘，且不会直接改写胜负函数；
- 能力成长有触发条件、代价和反制；
- 奇数裁判不会自裁，票型和依据完整，判例不回溯；
- 48 层门禁能说明缺失条件，十个周期能产生可验证的状态变化；
- 同一输入、种子、动作和规则版本能够重放出同一结算。

### 9.3 原创性验收

- 设计稿逐项检查是否包含外部作品专名、人物、台词、地点或具体剧情；
- 参考来源只出现在研究记录，不出现在世界内正文；
- 新角色即使去掉古典意象或参考提示，仍有独立的行为和机制理由；
- 新游戏能用本项目的规则书、事件流和裁判协议自洽运行；
- 任一关键叙事结论都能追溯到本项目的对局事实、判例或明确的原创设定。

### 9.4 对外发布门槛

满足以下条件才可称为“原创世界观切片”：

- 已锁定本切片使用的规则版本和术语表；
- 已完成一局完整回放，包含密态投影、能力记录和裁判记录；
- 已通过参考边界检查；
- 已证明演示中的叙事结果来自真实事件链；
- 已把未实现的长期内容标为计划或样例，没有把设想包装成已发生的世界历史。
