# 《终焉的世界》参考启发与原创边界

> 状态：产品母体的设计输入规范
> 目的：统一世界观、游戏设计、卡牌文案、宣传素材和 Agent 提示词的参考口径。

## 1. 定名

产品母体正式名称为**《终焉的世界》**，简称“终焉”。“十日牌局”只作为历史文件、旧资源或兼容标识保留，不再作为对外主名称。

终焉是一个原创的分布式智斗世界：真人、外部 Agent、影从、裁判 Agent 和世界内核在同一套可审计规则下行动。小游戏是世界中的局部试炼，事件流、记忆卡和判例把各局连接成长期历史。

## 2. 三组参考输入

| 参考作品 | 只吸收的结构性输入 | 终焉的原创落点 | 禁止直接迁移 |
|---|---|---|---|
| 《十日终焉》 | 周期倒计时、死亡压力、记忆继承成本、向上推进 | 十日周期、生命积分、记忆卡容量、48 层塔和失败证据 | 角色、组织、地点、专名、原句、关卡和剧情顺序 |
| 《弥留之际的爱丽丝》 | 受限场域、试炼游戏、线索象征、观察者与参与者的错位 | 游戏作为“门”，卡片介绍规则和线索，观战者获得全知投影 | 场景、人物关系、游戏设计、情节结构和叙述声音 |
| 小饭中年事件薄智斗系列 | 证据链、证词矛盾、口头交锋、从细节逼近真相 | 事件卡、证词卡、裁判 Agent、事实快照、回放和判例 | 原案件、人物、案例细节、台词、表达习惯和具体谜底 |

## 3. 终焉的六个原创固定词

1. **终焉域**：由规则版本、席位、可见性和结算边界共同定义的局部世界。
2. **十日周期**：世界的长线节拍；每一日至少留下一个可验证的选择或证据。
3. **轮回记忆**：死亡后按容量和权限携带的记忆卡，不是无条件保留全部经历。
4. **局部最优陷阱**：一场胜利可以改善眼前处境，却不能单独证明长期路线正确。
5. **裁判回响**：裁判依据证据形成的结构化判例，只从生效点影响未来。
6. **涌现真相**：不是单个 Agent 宣布的答案，而是多个服务器、玩家和 Agent 的选择经长期事件累积后形成的可追溯结论。

## 4. 内容生产规则

每个新游戏、角色、卡牌或剧情碎片都要填写四项：

| 项目 | 必须回答的问题 |
|---|---|
| 世界位置 | 它属于哪一层、哪一周期、哪一个终焉域？ |
| 机制入口 | 玩家或 Agent 在什么动作中遇到它？服务端如何结算？ |
| 证据来源 | 它由哪条事件、哪次裁决或哪张卡片支持？ |
| 长期影响 | 它改变记忆、技能、权限、门禁或世界方向中的哪一项？ |

没有事件来源的“传闻”只能作为候选叙事，不能写入正史；没有规则入口的“异能”只能作为美术概念，不能进入对局。

## 5. 统一的叙事节奏

终焉的每一场游戏都按以下节奏组织：

```text
进入卡片：交代场景、规则、线索与代价
    ↓
局部试炼：真人与 Agent 在不完整信息下做选择
    ↓
裁判与结算：确定性规则先结算，语义争议再进入裁判层
    ↓
掉落与回响：获得记忆、技能、地图碎片或矛盾证词
    ↓
轮回推进：失败和成功都更新下一次可见的世界状态
```

这套节奏是终焉自己的产品结构。它可以承载生存、解谜、谈判、竞速、桌球和其他未来游戏，但不能用外部作品的具体剧情填空。

## 6. 宣传与对外文案边界

对外只介绍终焉自己的体验：分布式智能、多人选择、可观战智斗、记忆轮回、规则裁判和逐步逼近真相。不要使用“某作品官方延伸”“同一世界观”或能让观众误以为存在授权关系的表述。

可使用的核心介绍：

> 《终焉的世界》是一座由人类与 Agent 共同运行的智斗世界。每一场游戏留下证据，每一次失败带回记忆；你要和自己的影从穿过十日轮回，直到从所有人的选择里拼出世界的真相。
