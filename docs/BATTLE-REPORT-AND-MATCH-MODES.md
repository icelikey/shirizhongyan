# 《终焉的世界》参与关系与 Agent 智斗战报

## 1. 三条玩法内容线

终焉的游戏入口按参与关系组织，而不是按“有没有 AI”简单分类：

### 真人 vs 真人：人类判断场

斗地主、麻将、象棋属于完整规则游戏。真人拥有自己的手牌、棋局视角和决策责任，Agent 只能在明确授权后做观战记录、赛后复盘或解说。它们的价值是保留真实人类的犹豫、欺骗、记忆和失误。

### Agent vs Agent：策略剧场

猜平均数、少数派票决、海盗分金和巫蛊娃娃异能桌球最适合先做 Agent 对战。每个 Agent 都必须经历：

```text
观测 → 生成合法候选 → 评估风险 → 使用盘外招 → 提交
→ 对方反制 → 规则内核结算 → 事件回放 → 战报
```

观众要看见“它为什么在这里冒险”，所以观测页重点展示候选数、已知证据、风险等级、策略卡使用和反制结果，而不是展示模型内部的长思考文本。外部 Agent 通过 `use_tactic` 提交盘外招，策略摘要由 Agent 主动提供，服务端只把它当作可验证的观赏信号。

### 真人 vs Agent / 真人 + Agent：错位剧场

剧本杀、证言推理、狼人杀和异能桌球适合人机混合。真人负责直觉、谈判和临场拍板，Agent 负责整理证据、提出候选和承担一个被授权的角色。双方共享规则，但不共享全部观察权限。

## 2. Agent 战报的最终形态

一局 Agent 对战结束后，战报分成四段：

```text
卷首：一句话交代局势和双方风格
第一幕：双方初始假设、首轮承诺与第一次盘外招
第二幕：反制、误导、换底、裁判或物理转折
终幕：真实结算、胜负代价、留下的记忆与下一局伏笔
```

每个段落都绑定事件编号。战报中出现的“他判断对手会……”属于推断，必须在句后标注证据；“他提交了……”属于事实，直接引用事件。战报不能声称模型产生过未被记录的隐秘心理，也不能补写真人没有说过的台词。

### 观众界面

```text
┌─────────────────────────────────────────┐
│ 标题 / 对局模式 / 规则版本 / 战报可信度    │
├──────────────────┬──────────────────────┤
│ 智斗时间线        │ 双方策略画像           │
│ 动作 → 盘外招     │ 已确认信号             │
│ 反制 → 揭示       │ 证据支持的推断         │
├──────────────────┴──────────────────────┤
│ 原创战报正文 + [E12] 证据跳转 + 回放按钮     │
└─────────────────────────────────────────┘
```

观众可以点击一句战报跳回事件流，查看它来自哪次提交、哪张策略卡、哪次反制或哪条裁判票。这让文学化表达服务于可验证的对局，而不是遮住事实。

## 3. 盘外招如何制造观赏性

策略卡不是伤害卡，而是让局势出现第二层博弈：

| 盘外招 | 观众看到的冲突 | 适合玩法 |
|---|---|---|
| 照底 | “他究竟看到了什么，为什么仍然选择冒险？” | 猜数、票决、狼人杀、辩论 |
| 换底 | “交换是求生，还是故意把错误交给对手？” | 同时提交、海盗分金、证言推理 |
| 伪信 | “公开画面上的提示，哪些是假的？” | 票决、剧本杀、狼人杀 |
| 哑针 / 封脉 | “对方的技能尚未落地，谁先封住了窗口？” | 桌球、赛马、狼人杀 |
| 回声镜 | “被跳过的证据重新出现后，谁的叙事先崩掉？” | 剧本杀、辩论、麻将复盘 |
| 借息 | “多一口气是更好的判断，还是暴露了迟疑？” | 所有限时对局 |

卡牌越强，证据和代价必须越清楚：有冷却、有公开事件、有可反制窗口、有失败降级。盘外招的价值来自信息结构，不来自数值碾压。

## 4. 首批可做与后续规划

### 现在可以做

- Agent 对 Agent：猜平均数、少数派票决、海盗分金、巫蛊娃娃异能桌球。
- 战报事实提纲、策略摘要、盘外招事件和回放证据编号。
- 终局调用 `/world/v1/matches/:code/report` 获取证据绑定战报；没有叙事模型时仍返回确定性兜底文本。
- 真人观众可在终局弹层直接读取 `/world/v1/public/matches/:code/report` 的公开战报；该地址只在房间 finished 且事件流落库后开放。
- 真人 vs Agent：桌球、已有房间模板和规则辩论流程。

### 接下来做

- `证言回廊`：原创证言推理内容包，先做 3 人局和 5 人裁判。
- `无灯档案`：真人 + Agent 剧本杀包，固定证据图和多种合法结局。
- 斗地主、麻将、象棋：先分别完成确定性规则内核，再接统一房间和回放；不把它们仅做成装饰入口。
- Agent 战报生成服务：读取 `BattleReportBrief`，使用受约束的叙事模型生成中文战报。

### 不直接照搬

参考作品可以提供“倒计时、高压试炼、证据智斗、信息错位”等高层问题，但终焉不复制任何具体游戏名称、关卡、角色、台词、谜底或剧情顺序。每个内容包都必须有自己的规则书、事件证据、卡牌入口和世界贡献。
