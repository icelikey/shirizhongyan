# 终焉 · 开场 PV 与玩法播片卡

## 交付目标

注册完成后，玩家进入一段 16:9 横屏开场 PV。PV 播放完毕后，入口按钮亮起；点击后进入“世界悬浮”入口层，看到动态旋转的十日日轮与持续运行的十日倒计时，再进入大厅。

每个真实小游戏的顶部都保留“玩法卡”入口。第一次进入自动打开，之后可以随时回看。玩法卡按“画面前瞻 → 操作 → 世界冲突 → 线索”组织，服务于现场观众快速理解，而不是用长段文字阻塞对局。

## 当前链路

```text
注册 / 立契
  -> 开场 PV（30 秒，1920 × 1080）
  -> PV 结束，解锁「进入终焉世界」
  -> 世界悬浮入口（动态旋转 + 第 N 日倒计时）
  -> 墨染转场
  -> 大厅 / 真实牌局
  -> 玩法卡（每个游戏独立、可重复打开）
```

实现位置：

- `app/src/components/onboarding/WorldIntroFilm.tsx`：PV、声音开关、30 秒进度、世界序章卡。
- `app/src/components/onboarding/WorldGate.tsx`：PV 后的世界悬浮入口。
- `app/src/pages/Home.tsx`：注册完成后的状态编排与进入大厅。
- `app/src/components/game/GameIntroCards.tsx`：真实小游戏的 16:9 玩法卡。
- `app/src/data/gameIntros.ts`：每个玩法的剧情、操作、世界线索。
- `app/public/assets/onboarding/ending-opening-pv.mp4`：开场 PV。
- `app/public/assets/onboarding/world-gate-v1.png`：世界悬浮入口主视觉。

## 世界悬浮入口

入口层不依赖额外滚动：

- 中心十日日轮持续旋转，外侧轨道逆向旋转。
- 中心环直接读取当前账号的 `createdAt`，显示第几日与距离终焉的倒计时。
- 背景使用无文字横屏主视觉，中文标题、按钮和倒计时全部由网页叠加。
- 点击「进入牌局之间」后才进入大厅；倒计时不会因为入口层关闭而停止。

## 玩法卡内容合同

每个 `GameIntroSpec` 可以填写：

- `visual`：16:9 横屏主视觉，建议只放环境、角色、动作和光效，不在图内生成中文。
- `subtitle`：一句话说清楚观众要看什么。
- 三张卡：
  1. 入局：玩家实际要做什么。
  2. 冲突：Agent、真人、规则或裁判之间如何产生张力。
  3. 接入：外部 Agent 如何读取规则、入座和行动。
- 每张卡的 `clue`：把本局事件接回终焉世界，作为后续可读取的线索。

## 文字层原则

- 画面只承担氛围、冲突和因果，不把规则小字交给图像模型。
- 标题不超过一行，操作说明用“动作 → 等待 → 揭晓”表达。
- 线索必须是原创的终焉世界碎片，避免直接搬运其他作品原文。
- 观众先看到行动和结果，再看到 Agent 接入方式；技术协议放在单独的 Agent 接入页。

## 验收

1. 新账号注册后会自动打开 PV。
2. PV 未到 30 秒时，“进入终焉世界”保持禁用。
3. PV 播放结束后，按钮亮起；静音切换不影响进度。
4. 点击进入世界后，能看到旋转轨道、十日日轮与倒计时。
5. 点击进入牌局之间后，墨染转场进入大厅。
6. 每个联机小游戏首次打开时出现 16:9 玩法主视觉和三张说明卡。
7. 玩法卡可用按钮和滑动切换，关闭后可从顶部再次打开。
8. `pnpm check`、`pnpm test -- --run`、`pnpm build` 通过，公网健康检查和协议发现仍返回 200。
