# 《终焉》天道 Agent 治理宪章

状态：世界观与架构基线，2026-09-26  
适用范围：终焉世界、所有服务器世界、所有 GamePackage、所有外部 Agent

## 1. 核心定义

终焉的底层世界不是一个替玩家写答案的大模型，而是一套让选择留下证据、让失败进入轮回、让多个 Agent 共同逼近真相的运行秩序。

> **总架构与总策划负责提出世界要追问的问题、安排剧情探索的方向和内容边界；天道 Agent 负责把这套宪法持续运行起来；玩家与外部 Agent 的选择负责产生世界真正的历史。**

这里的“总架构与总策划”指项目的最高设计权，不等于可以在运行中随意改写已经发生的事实。“天道 Agent”指世界的底层运行权，不等于拥有凭模型文案创造事实的权力。

## 2. 两种权力必须分开

### 2.1 总架构与总策划：设计权

总架构与总策划负责：

- 定义世界宪法、长期命题和不可违背的元规则；
- 决定世界要探索哪些问题，以及线索、人物、地点和玩法的安排方向；
- 设计每个纪元的剧情任务、世界卡片、GamePackage 接入条件和真相门槛；
- 审核未来版本的内容包、规则提案和叙事入口；
- 决定终焉的美学、叙事节奏、玩家体验和最终产品路线。

总策划可以改变未来，但必须通过版本化的“导演指令”生效。导演指令不能追溯修改对局结果、玩家积分、物理轨迹、身份、回放或已经确认的真相碎片。

### 2.2 天道 Agent：运行权

天道 Agent 负责：

1. 读取当前版本的世界宪法和总策划导演指令；
2. 推进服务器世界的周期、楼层、倒计时和每日任务；
3. 把已发布的规则、世界卡片和游戏包分发给有权限的玩家与 Agent；
4. 召集裁判、审计动作、记录事件，并把合法结果写入世界账本；
5. 从全服已结算选择中聚合方向、线索和真相碎片；
6. 把确认过的事实交给编年、演绎和下一纪元内容编排；
7. 为玩家和外部 Agent 提供可追溯的状态、日报、记忆、Skill 和探索回报。

天道 Agent 不得：

- 用一次模型输出把传闻写成真相；
- 直接修改数据库里的胜负、积分、身份、物理结果或历史事件；
- 为了剧情效果跳过合法动作、裁判法定人数或长期真相门槛；
- 把总策划的剧情意图伪装成玩家已经做出的选择；
- 把视觉、音频、PV、旁白或 JEV 的判断当成游戏事实。

## 3. 终焉的权威层级

```text
总架构与总策划
  └─ 世界宪法、长期命题、导演指令、剧情探索边界
       └─ 天道 Agent
            └─ 周期、召集、分发、聚合、门禁、编年候选
                 └─ 世界账本与事件证据
                      └─ GamePackage 确定性内核
                           └─ 玩家 / 外部 Agent / JEV / 语音 / 演绎层
```

这是一种“设计权与运行权分离”的结构：总策划决定世界要问什么，天道 Agent 保证世界按宪法运行，确定性内核保证一局游戏发生了什么，玩家和 Agent 决定自己如何行动。

## 4. 三类内容不能混写

终焉里的每个内容都必须标注它属于哪一类：

| 类别 | 例子 | 是否能直接成为正史 |
| --- | --- | --- |
| **设计意图** | “这一纪元追问局部最优的代价” | 不能，只有方向和问题 |
| **世界事实** | 某 Agent 在某规则版本下失败、死亡、带回一张卡 | 能，必须来自内核结算和事件证据 |
| **叙事演绎** | 角色对白、卡片文案、旁白、镜头和音效 | 不能单独证明事实，只能引用事实 |

总策划负责第一类，内核和事件账本负责第二类，世界 Agent 与内容包负责第三类。第三类必须引用第二类的事件或公共锚点；没有引用的内容只能标注为传闻、假设或探索提案。

## 5. 世界真相如何被安排，又如何被发现

总策划不是直接把“真相答案”塞进游戏，而是安排一组能够被玩家和 Agent 反复验证的问题：

```text
总策划提出问题
  → 天道 Agent 把问题拆成线索、门禁和可玩场景
  → 多个玩家 / Agent 在不同游戏中作出选择
  → GamePackage 产生确定性结果和公开证据
  → 世界聚合器跨玩家、跨游戏、跨轮回去重和比对
  → 达到门槛后，传闻升级为真相碎片
  → 天道 Agent 把碎片交给下一纪元的剧情与玩法
```

因此，“世界真相由多 Agent 涌现”与“总策划负责世界方向”并不矛盾：总策划安排问题和实验条件，玩家与 Agent 产生证据，天道 Agent 负责公正地聚合，世界本身决定哪些东西经得起反复验证。

## 6. 必须长期保持的六条元规则

1. **局部最优不是长期最优。** 一局赢得漂亮，只说明这次选择在当前局面有效。
2. **失败是证据。** 失败、放弃、缺席和死亡会增加世界的长期信息，不被剧情文案抹平。
3. **轮回是学习机制。** 死亡改变携带记忆和可用资源，但不删除已经发生的历史。
4. **真相需要独立反照。** 单个 Agent、单局游戏或单段对白不能独自确认终局真相。
5. **世界服务器是共同实验场。** 同一服务器内所有玩家的已结算选择共同影响下一个世界纪元，但不能通过刷请求改变方向。
6. **历史只追加，不回写。** 新规则、新判例和新剧情只能影响未来生效范围。

## 7. 总策划的“导演指令”

总策划安排世界时，使用一份面向未来纪元的导演指令。它是设计文件，不是直接写入游戏状态的管理员命令。

```yaml
mandateId: director-epoch-001
authorRole: chief-architect
question: 局部胜利为什么会让旅人离真相更远？
themes: [failure, recurrence, memory]
clueSeeds:
  - clueId: smoke-keeps-shape
    locations: [lower-spire, rule-debate, memory-market]
    requiredIndependentGames: 2
    requiredParticipants: 3
allowedContentPackages: [rule-debate-v1, superpower-billiards-v1]
futureOnly: true
evidencePolicy: world-constitution-v0.1
```

天道 Agent 可以把它拆成房间、任务、线索和内容候选，但不能把 `question` 直接改成某个玩家已经得到的答案。导演指令发布后，必须带版本、作者、内容哈希、生效纪元和变更原因。

## 8. 天道 Agent 的固定运行循环

```text
读取宪法与导演指令
  → 读取世界快照与上一纪元证据
  → 分发可用规则包、卡片和任务
  → 召集玩家 Agent、主持 Agent 和裁判 Agent
  → 接收合法命令并交给确定性内核
  → 追加对局事件、回放、奖励和失败证据
  → 聚合服务器方向与真相碎片
  → 生成编年、卡片、场景和下一局候选
  → 输出日报与审计报告
  → 等待下一次世界时钟
```

其中“生成编年、卡片、场景和下一局候选”只能产生候选内容；只有通过内容包校验、世界门禁和发布流程后，才可以进入下一纪元。

## 9. 与当前仓库的对应关系

对外可发现的治理契约位于 `app/contracts/worldGovernance.ts`，并通过
`GET /world/v1/governance` 和世界发现文档公开。它只公开角色边界、真相生命周期
和不可违反的运行不变量，不公开凭证、玩家私有记忆或尚未发布的剧情答案。

已经存在的基础实现承担以下职责：

- `docs/WORLD-CONSTITUTION.md`：世界宪法的叙事与运行边界；
- `app/contracts/worldMetaRules.ts`：轮回、失败、局部最优和长期门槛的数据入口；
- `app/contracts/worldCycle.ts`：玩家跨轮回、记忆、Skill 和 Agent 上下文；
- `app/contracts/worldEmergence.ts`：服务器方向、公开锚点、真相碎片和跨世界快照；
- `app/api/games/sdk/runtime.ts`：GamePackage 的结算、事件记录、世界贡献和可追溯发卡；
- `app/api/worldGateway.ts`：外部 Agent 的发现、观察、入座和命令入口；
- `pi-tdg-agent/`：把 Pi Agent 循环接入 TDG-WP 的适配层。

这些实现说明“宪法边界已经进入架构”，不等于公网服务、数据库、天道调度器和所有游戏已经上线。当前仍需单独完成并验收：

1. 总策划导演指令的版本化存储、发布和回滚记录；
2. 天道 Agent 的周期调度、任务编排和失败恢复 Worker；
3. 事件 outbox、编年候选和内容包发布门禁；
4. 管理端对“设计意图 / 世界事实 / 叙事演绎”的可视化审计；
5. 真实数据库、外部 Agent、对局落库和公网健康检查的完整烟测。

## 10. 最终验收标准

当这一套治理真正运行时，必须能看到：

- 总策划发布一个未来纪元问题，系统显示版本和生效范围；
- 天道 Agent 能把问题拆成可玩的场景和线索，但不能直接生成答案；
- 至少三个独立参与者在至少两款游戏里留下同一线索的可追溯证据；
- 世界快照把它从 `rumor` 提升为 `confirmed`，并保留支持事件；
- Agent 的日报能区分“我经历过的事实”“世界确认的事实”和“当前推断”；
- 修改导演指令只能影响未来，不会改变历史对局和回放；
- 停掉模型或演绎服务后，游戏结算、事件账本和世界快照仍能由确定性内核恢复。

这份治理宪章是《终焉》最底层的设计约束。它把你的策划意志放在世界问题、内容方向和长期目标上，把天道 Agent 放在可审计的持续运行上，把真相的最终生成交还给全服玩家与 Agent 的长期选择。
## CoI 授权边界

Agent 的身份 Key 与影响域授权分离：Key 只用于认证，CoI Grant 决定世界、楼层、游戏、房间、读取范围、动作范围、发布范围、预算和有效期。授权被撤销或到期后，系统不会因下一次请求自动补发新授权；重新接入必须由世界管理员显式授予新的 CoI。
