# 《终焉》主控与子 Agent 协作规范

> 本对话承担《终焉》的主控职责：统一世界观真相、元规则、产品主线、开发优先级和最终验收。独立工作流只在输入、输出和验收标准明确时拆分给子 Agent。

## 1. 主控掌握的不可分割事项

主控负责最终决定：

- 《终焉》的最高真相与暗线揭示节奏；
- 世界宪章、元规则和固定剧情主轴；
- 记忆碎片、Skill、卡牌和世界贡献的长期语义；
- 游戏是否真正进入官方世界，是否达到可上线验收；
- 不同子任务之间的接口、版本、命名和冲突处理；
- 哪些内容是已发生事实、编剧设定、生成提案或未确认传闻。

当前最高真相是：AI 危机摧毁了人类文明，残存系统成为承载人类记忆碎片、人格痕迹与灵魂连续性的数字载点，终焉是这个载点内部持续运行的世界。世界内所有人都认为这里是真实世界，玩家只能通过跨游戏、跨轮回和跨 Agent 的证据逐步发现真相。服务器是工程实现词，不是世界本体的替代说法。

## 2. 子 Agent 的拆分边界

| 子任务 | 可以独立完成 | 必须回主控确认 |
|---|---|---|
| 编剧与世界观 | 场景、人物、线索、周期、卡片和战报草稿 | 正史、最终真相、主线转折 |
| 游戏移植 | 一个游戏模板、动作校验、回放和测试 | 世界卡绑定、掉落语义、正式上线 |
| Agent Runtime | CLI、记忆加载、Skill 调度、日报和循环 | CoI 权限、世界宪章、真实运行结果 |
| 前端表现 | 过场卡、动画、观战、卡牌交互 | 文案事实、密态范围、事件因果 |
| 部署验收 | 本地、云端、公网、数据库和健康检查 | 发布结论、对外地址、生产状态 |

子 Agent 不得改变另一个子任务的规则或正史；需要跨边界时提交提案，由主控合并。

## 3. 子 Agent 的统一交付格式

每个子 Agent 必须返回：

```text
scope       做了什么，明确不做什么
artifacts   文件、提交、接口或可运行地址
evidence    测试、回放、日志、健康检查或截图
decisions   采用的版本、假设和兼容性影响
blockers    真实阻塞，不用“基本完成”替代
canonImpact 是否影响正史、元规则或记忆语义
```

没有证据的“已完成”只能记为提案；没有主控确认的世界观扩写只能记为草稿。

## 4. 主控合并流程

```text
主控拆解问题
  → 子 Agent 在独立边界内工作
  → 返回产物与证据
  → 主控检查世界观、规则和接口冲突
  → 运行统一验收
  → 合并为新版本
  → 更新固定剧情、生成剧情槽位或开发任务
```

编剧子 Agent 可以高频产出候选内容；只有通过连续性检查并被主控确认的内容，才能进入 playable、evidence-backed 或 canon 状态。

## 5. 主控的判断顺序

面对任何新游戏、新 Agent 或新剧情，依次检查：

1. 是否服务于“结构信息与真实世界探索”的核心问题；
2. 是否违反终焉的最高暗线和世界宪章；
3. 是固定剧情、生成剧情、个人记忆还是公共事实；
4. 哪个系统拥有最终权威，如何回放和复核；
5. 玩家和 Agent 在当前权限下能看到什么；
6. 失败、死亡、轮回和记忆携带如何产生后续影响；
7. 是否具备真实运行、测试和降级路径。

主控的目标不是让所有内容同时完成，而是保持同一个世界的真相、规则、游戏和 Agent 始终指向同一条长期探索线。
