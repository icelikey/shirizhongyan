# 终焉世界层：十日、生命积分与记忆轮回

这份规则是所有小游戏之上的世界层合同。小游戏只负责本局的合法动作、胜负与回放；世界层负责旅人的时间、生命、层数、记忆和异能。两者不能互相越权。

## 1. 十日周期

- 一个轮回包含 10 日。
- 每日必须完成 3 场真实游戏。观测、等待、进入房间但没有完成结算，都不算完成一局。
- 一日结束时，未完成的每一局按 12 点生命积分记为时间债。
- 10 日结束后进入下一轮回，旅人仍保留当前世界层、已加载记忆和异能成长；日数重新从 1 开始。
- `worldContext.dailyGames` 是 Agent 每次观测都必须读取的当前配额，不允许策略程序自行把“已计算”说成“已完成”。

## 2. 生命积分

- 初始生命积分为 100，上限为 100。
- 胜局 +10，败局 -7，平局不变，主动放弃 -10。
- 生命积分归零立即宣告死亡，当前局之外的碎片、已确认战绩和世界判例不回滚。
- 死亡会中止当前爬塔局，将旅人送回第 1 层；当前层、临时牌组、遗物和金币属于本次轮回的消耗品。
- 生命积分由世界层结算，小游戏不能直接篡改；小游戏只提交 `win/loss/draw/abandon` 结果。

## 3. 爬塔与生命危机

原型保留 48 层世界塔。完成当日三局且至少赢下一局，世界层上升一层；实际战斗地图可以先用 3 层 Demo 承载，但世界进度仍按 48 层合同记录。

固定危机层如下：

| 层 | 危机 | 生命临界线 | 必须留下的证据 |
|---:|---|---:|---|
| 1 | 入塔危机 | 20 | 第一次欠局形成轮回刻痕 |
| 6 | 失声 | 55 | 第三局必须携带至少一张世界记忆 |
| 12 | 裂桥 | 50 | 第三局结算前完成规则复述或质询 |
| 24 | 倒日 | 40 | 异能充能不足时记录时间债 |
| 36 | 回声 | 30 | 死亡时至少带回一张伤痕记忆 |
| 48 | 终焉门 | 20 | 第 10 日三局完成并通过终局裁判才可离开轮回 |

危机不是纯 UI 提示。`floorCrisis()` 会给出当前层的危机条款，Agent 和网页必须展示同一条款；具体小游戏是否满足条款由世界事件或奇数裁判团留下证据。

## 4. 记忆卡

每场游戏可以产生一张世界记忆。记忆卡包含：来源大陆、叙事摘要、Agent 指令和表现层效果。记忆卡可以影响信息投影、规划预算、路线选择和争议解释，但不能绕过 GameModule 的合法动作检查，也不能改写已经结算的胜负。

当前首批记忆卡：

- 第一条规则：每天三局，识别时间债。
- 影从之誓：读取契约影从与真人的分歧。
- 碎时漏斗：临界阶段优先完成合法动作。
- 第二次猜测：生成一个反共识候选动作。
- 未被听见的发言：保留被忽略的异议。
- 失败的提案：读取承诺与兑现记录。
- 未定判例：遇到歧义时请求 3/5/7 名裁判复核。
- 轮回刻痕：死亡后区分事实、推断和带回记忆。

默认最多加载 3 张记忆卡进入 Agent 上下文。白泽、青囊异能各增加 1 个记忆槽，百晓生增加 2 个，最多 8 个槽位；网页上的“Agent 记忆载荷”卡片会显示当前扩容并允许切换加载状态。Gateway 的 `worldContext.memoryCards` 和 `worldContext.directives` 是外部 Agent 的实际读取入口。

记忆之外，每个旅人还有两个可持续积累的线索背包：地图碎片记录地点证据，笔记残卷记录可复述的事件句子。抵达第 6、12、24 层等危机楼层，或通过外部游戏上报特定地点时，会触发对应线索；触发结果会写入 `worldContext.backpack`，并可获得一张新的特殊记忆。线索只提供信息、路线和解释材料，不能改写小游戏的合法动作或既定胜负。

## 5. 死亡与回到底层

死亡弹层必须让玩家从当前轮回的候选记忆中选择不超过当前记忆槽位容量的卡片。确认后：

1. 回到第 1 层，生命恢复为 70；
2. 轮回编号 +1，日数回到第 1 日；
3. 临时牌组、遗物和金币清空；
4. 选择的记忆卡成为下一轮 Agent 的初始载荷；
5. 异能等级保留并增加一次充能，成为“带着失败学会的能力”；
6. 没有被选择的记忆仍可留在世界事件流中，但下一轮不会自动进入 Agent 上下文。

“活着”与“登上一层”都保留当前记忆；“死亡”只允许带回明确选择的记忆。这使记忆既是成长资源，也是死亡时的取舍。

## 6. Agent 每次决策的加载顺序

外部 Agent 在 `join` 和 `observation` 响应中读取 `worldContext`，顺序固定为：

1. `status / lifeScore / floor / cycle / day`：先判断还能承受几次风险；
2. `dailyGames`：确认今日剩余场次；
3. `crisis`：确认当前层的生命危机条款；
4. `ability`：读取开局异能、等级、充能和描述；
5. `memoryCards` / `directives`：将已加载记忆转成当前策略约束；
6. `observation` / `rulebook`：最后才根据本局规则生成合法动作。

Agent 必须把“事实、记忆指令、自己的推断”分开记录。记忆卡可以改变它如何解释信息，不能让它提交规则书中不存在的动作。

## 7. 元规则：局部最优不能直接通往真相

“局部最优不等于长期最优”是终焉世界的宪章原则，不是任何一款小游戏的胜负条件。每个 GamePackage 只提交本局已结算的事实；世界层把这些事实编译为跨局证据：

- `recurrence.localWinStreak` 只表示当前轮回的局部连胜；连续胜利不会单独解锁真相。
- `recurrence.failureCount` 记录失败、放弃和缺席留下的证据，`deathCount` 记录死亡轮回；两者会推动长期洞察和真相路径。
- `memoryArchiveIds` 保存已经发现的记忆目录，`memoryCards` 和 `equippedMemoryIds` 仍受当前异能容量限制。
- `longTermGate` 汇总失败、死亡、真相和地图碎片四类门槛。门槛未满足时，Agent 只能提出探索假设，不能把局部胜利或模型叙事宣称为终局真相。

死亡会保留轮回统计、世界事件和记忆档案，只让玩家从当轮候选中选择有限卡片带回底层。新判例和新剧情可以改变未来内容供给，不能改写已经结算的对局与回放。完整宪章见 [`docs/WORLD-CONSTITUTION.md`](WORLD-CONSTITUTION.md)，数据入口见 `app/contracts/worldMetaRules.ts`。
