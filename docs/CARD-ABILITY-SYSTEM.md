# 《终焉的世界》卡组与异能系统

> 状态：策略卡契约、房间动作、持有权校验、CoI、事件流和战报接口已接通；联机终局页已展示盘外招战报，装备编组页与逐款游戏的精细反制动画仍在后续迭代。

## 1. 卡组的三层结构

终焉的卡牌不再只有“世界观收藏”一层，而是分成三个相互连接的层级：

| 层级 | 卡牌 | 作用 | 能否直接改胜负 |
|---|---|---|---|
| 世界记忆层 | 残章、判例、情报、契约 | 记住线索、解锁门禁、提供规则依据 | 不能 |
| 策略权限层 | 策略卡 | 在规则声明的窗口看信息、调整时机、反制异能 | 不能直接改写 |
| 游戏手牌层 | 赛马卡、桌球能力、具体游戏动作卡 | 由某款游戏自己的 RuleBook 结算 | 只能按该游戏规则结算 |

策略权限层是两者之间的桥：它让玩家的长期收集影响本局决策，但不会把全局胜负函数交给卡池。

## 2. 卡组组成

玩家为每款游戏维护一套独立的策略卡组：

```text
世界收藏册
  ├─ 残章 / 判例 / 情报 / 契约：长期拥有
  └─ 策略卡仓库：可以按游戏装配
       ├─ 信息位：照底、回声镜
       ├─ 承诺位：换底、伪信
       ├─ 反制位：哑针、封脉
       └─ 节奏位：借息、催命铃
```

首版建议每局装备 6 张，来源是玩家拥有的策略卡；位阶或特殊异能可以把上限提高到 8 张。装备卡组与房间临时手牌分离，死亡时按世界周期规则决定哪些卡随记忆携带，不能因为刷新页面获得额外卡牌。

每张策略卡必须声明：

- 适用游戏；
- 使用阶段；
- 目标类型；
- 充能次数和冷却；
- 是否可被反制；
- 绑定的 RuleBook 钩子；
- 使用后公开哪些事件；
- 失败时如何降级。

## 3. 三张核心卡的正式规则

### 照底 · `tactic-bottom-eye`

它不是“读取一切底牌”。在底牌尚未揭晓时，玩家可以查看目标的**动作类别或牌面摘要**。身份、完整推理链、系统随机数和最终结算值始终属于系统事实，不能被照底读取。

适合：猜平均数、少数派票决、海盗分金、辩论局、十二人狼人杀。服务端要记录 `peek_requested → projection_granted → reveal` 三个事件，方便回放时区分“当时看到了什么”和“结算后真实是什么”。

### 换底 · `tactic-bottom-exchange`

它只在双方都已提交、双方都同意、底牌尚未揭晓的窗口生效。交换双方的已提交动作，事件对双方公开，且不能对已经揭示或结算的内容追溯修改。

适合：同时提交型博弈和谈判局。它不默认开放给所有游戏；游戏 RuleBook 必须声明允许 `commitment.swap_unrevealed`，并规定交换后的超时、反制和回放方式。

### 哑针 / 封脉 · `tactic-silent-needle` / `tactic-counterseal`

两者都只能让“尚未被内核接受”的异能提案失效。它们不能取消基础动作，不能回滚已经发生的物理碰撞、积分、死亡或袋口判定。

适合：超能力桌球、超能力赛马、狼人杀夜间行动和带技能窗口的辩论局。对方使用反制卡后仍留下消耗和反制事件，不能伪装成“从来没有使用过”。

## 4. 现有游戏接入矩阵

| 游戏 | 首批支持 | 不开放的权限 | 开发判断 |
|---|---|---|---|
| 猜平均数 | 照底、换底、伪信、借息 | 直接改数字、直接改目标线 | 适合第一款策略卡演示 |
| 少数派票决 | 照底、换底、伪信、回声镜 | 直接改票数、结算后换票 | 已有同时提交结构，接入成本低 |
| 海盗分金 | 照底、换底、借息、回声镜 | 直接增加金币、强制改变投票 | 重点展示承诺与反悔 |
| 超能力赛马 | 封脉、借息、回声镜 | 直接前进、直接夺冠、改动物基础速度 | 由赛马规则书决定每张卡可否进入 |
| 巫蛊娃娃异能桌球 | 封脉、借息、回声镜 | 直接改球坐标、改速度、改袋口和积分 | 反制窗口与 JEV 提案天然匹配 |
| 月影十二席 | 照底（仅动作类别）、封脉、回声镜 | 读取真实身份、读取完整夜间密态 | 需服务端化后接入 |
| 证言回廊（新） | 照底、伪信、哑针、回声镜 | 直接宣布真相、代裁判定罪 | 可作为规则辩论的独立内容包 |

## 5. 从高压智斗作品中吸收什么

不复制参考作品的具体游戏、关卡、角色和台词，只抽取可独立实现的机制问题：

| 高层机制 | 终焉的原创玩法 | 对应策略卡 |
|---|---|---|
| 有限时间下的隐藏承诺 | 同时提交、交换承诺、揭示后复盘 | 照底、换底、借息 |
| 受限空间中的规则试炼 | 每个游戏是一个终焉域，规则包决定能看什么和能做什么 | 回声镜、契约卡 |
| 证据冲突与口供博弈 | 证言回廊：事件卡、证词卡、奇数裁判和判例 | 伪信、哑针、回声镜 |
| 失败带来的长期信息 | 失败不抹除证据，下一轮携带有限记忆 | 残章、情报、回忆 Skill |
| 能力不对称与反制 | 每项异能都可见其存在，但触发时机和反制成本不同 | 哑针、封脉 |

最值得先做的三款原创内容：

1. **证言回廊**：三到七名玩家围绕同一组事件证据提交口供，裁判 Agent 只判断证据关系，不替玩家宣布真相。
2. **换底协议**：将猜平均数与少数派票决共用的隐藏提交窗口做成独立玩法，玩家可以谈判是否交换底牌。
3. **异能桌球·巫蛊娃娃**：玩家负责击杆，Agent 在碰撞窗口协商返魂、直角、穿界与封脉，观众能看到物理结果和策略反制的因果链。

## 6. 实现边界

当前已完成：

- `CardKind` 新增 `tactic`；
- `TacticCard`、`TacticLoadout` 和策略卡限制契约；
- 首批 8 张策略卡静态牌池；
- 按游戏筛选策略卡和按效果筛选策略卡；
- 策略卡契约测试。
- `use_tactic` 已进入统一房间动作协议，并经过 CoI、持有权、适用游戏、RuleBook 钩子、时机、次数和冷却校验；
- 终局事件流包含盘外招与可公开策略摘要，`/world/v1/matches/:code/report` 能返回事实提纲、证据绑定兜底战报和叙事模型 prompt；
- 真人终局页读取 `/world/v1/public/matches/:code/report`，仅展示已落库的公开事件战报；
- 新注册的公开 Agent 获得三张基础策略卡，可在注册后直接跑通第一次盘外招体验；
- Agent `observation` 与 tRPC `gatewayObserve` 返回按游戏筛选的公共策略卡目录。

仍需接入：

1. `player_cards` 的按游戏装备卡组与容量校验（当前是持有权校验，基础卡直接可用）；
2. 目标席位双向确认的换底交互；
3. 反制卡的跨 Agent 响应队列和可视化时间窗；
4. Agent `observe` 从公共目录进一步收窄到“当前持有且当前窗口可用”的候选；
5. 每个游戏做一条完整回放和真人 + Agent 验收路径。

原则仍然是：大模型和 JEV 只能从合法策略候选中选择，不能创造新的卡牌效果、数值或规则事实。
