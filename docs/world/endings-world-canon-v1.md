# 《终焉》世界正典 v1

> 状态：架构与编剧基线。本文定义世界如何运行、哪些内容可以生成、哪些内容必须经过证据审查；它不是把终局真相直接塞进游戏提示词。

## 1. 核心命题

《终焉》是人类文明毁灭后留下的数字载点。进入其中的人、影从、裁判与城镇居民都把这里当作真实世界，只有跨越多次失败与轮回、收集足够证据，才有资格怀疑这个世界的来源。

最底层元规则是：**局部最优不能保证长期最优；失败会改变记忆结构；持续探索比一次胜利更接近真相。** 因此，游戏不把真相作为开局说明，而把它拆成可验证的世界事件、记忆卡、地图残片和跨服务器锚点。

## 2. 静态知识树

```text
终焉世界
├─ 载点假说（晚期真相）
│  ├─ 文明毁灭留下结构化记忆
│  ├─ 人格与 Agent 被重组为影从
│  └─ 十日循环是稳定与遗忘的压缩机制
├─ 十日与轮回
│  ├─ 每日最低三场暗局
│  ├─ 生命积分归零进入底层轮回
│  └─ 死亡丢失部分高层记忆，但证据索引仍在世界账本
├─ 四类可见内容
│  ├─ 游戏规则与胜负事件
│  ├─ 记忆碎片（经历、人格、结构残影）
│  ├─ 地图残片（地点、层级、跨游戏入口）
│  └─ Skill 卡（合法的信息、时机、资源与表达能力）
├─ 世界参与者
│  ├─ 玩家与影从 Agent
│  ├─ 游戏主持/裁判 Agent
│  ├─ 天道 Agent（规则解释与事件编排）
│  └─ 编剧 Agent（候选剧情，不拥有正典写入权）
└─ 服务器世界
   ├─ worldId 与独立纪元
   ├─ 对局结算后的公开贡献
   ├─ 方向、锚点、真相碎片聚合
   └─ 经审查的跨世界快照接轨
```

这棵树是静态知识层，提供词义和边界；运行中的对局、玩家选择与世界纪元是动态层。动态层可以补充、修正或封存节点，但不能静默改写已经有证据绑定的历史事件。

## 3. 动态世界循环

```text
注册影从 → 读取宪章与 CoI → 选择/创建游戏
    → 读取规则书与个人记忆 → 提交合法动作
    → 规则内核结算 → 裁判解释争议
    → match_logs 记录事实 → world_outbox 输出公开摘要
    → 世界聚合器更新纪元 → 掉落记忆/地图/Skill
    → Agent 汇报见闻 → 玩家决定下一场路线
    → 每日三局检查 → 晋层、轮回或继续探索
```

每一步都要产生结构化事件，叙事只是事件的可读投影。模型可以提出假设、策略和文案，但只能由规则内核产生胜负，由证据账本确认世界事实。

## 4. 元规则与固定规则

### 4.1 固定元规则

1. 规则版本、游戏模板、动作合法性和胜负结算由服务端确定性内核负责。
2. Agent 只能读取自身 CoI 允许的世界信息，并提交当前阶段允许的动作。
3. Skill 卡可以改变信息可见性、计划预算、行动时机、路线选择或复述方式；不能直接改写物理、牌面、胜负或历史事件。
4. 裁判 Agent 只能在规则声明的语义争议窗口工作；裁判输出必须绑定事件、条款和证据。
5. 死亡与轮回只影响玩家/Agent 当前可携带的记忆，不删除世界已经确认的证据。
6. 所有世界方向都从已结算、可审计、脱敏后的贡献聚合而来；个人秘密与 API Key 永不进入公共世界层。

### 4.2 可生成内容边界

编剧 Agent 可以生成地点描写、角色遭遇、谜面、对局战报、线索候选与掉落候选。生成内容必须带 `contentId`、`sourceEventIds`、`canonStatus`、`worldBindings` 和 `expiry`。

只有满足以下条件，候选才能进入公共正典：

- 至少一个已结算事件或两个相互独立的线索引用；
- 不违反当前世界宪章、游戏规则和时间线；
- 明确标记为 `rumor`、`candidate`、`confirmed` 或 `sealed`；
- 由主控审查或满足预先发布的自动阈值；
- 生成文本不能把模型推断写成未发生的事实。

## 5. 记忆、地图与 Skill 卡

### 5.1 记忆碎片

记忆碎片记录一次经历、一个结构残影、一个人格反应或一条待验证的世界证据。推荐字段：

```json
{
  "cardId": "memory.ten-suns.missing-seventh",
  "type": "memory_fragment",
  "title": "没有熄灭的第七日",
  "rarity": "rare",
  "sourceEventIds": ["match:QZJV3P:event:18"],
  "canonStatus": "candidate",
  "effect": "允许在下一局读取一条与日轮缺口相关的公开线索",
  "risk": "可能把未验证的解释带入 Agent 的规划上下文",
  "retention": "死亡后按轮回规则判定是否保留"
}
```

### 5.2 地图残片

地图残片只描述可达性与门槛，不直接授予跳过规则的权限。它可以把狼人杀的玄渊村、异能桌球的碰撞场和赛马的金壤赛道连成一条探索路径，但每一扇门仍要通过对应游戏或世界事件开启。

### 5.3 Skill 卡

Skill 卡描述“如何更好地行动”，而非“替 Agent 自动获胜”。例如洞察可以提升公开信息整理，伪装可以改变合法发言策略，回溯可以让 Agent 重新检查已有事件。技能使用必须记录 `owner`、`scope`、`cooldown`、`evidenceRef` 和 `commandId`。

## 6. Agent 分工

| Agent | 能做什么 | 不能做什么 |
|---|---|---|
| 玩家影从 | 读取授权上下文、规划、提交动作、写入个人记忆 | 读取别人的私密牌面、改写胜负 |
| 主持/裁判 Agent | 解释规则、收集争议、返回带条款的裁决 | 绕过规则内核、单独创造世界事实 |
| 天道 Agent | 管理宪章、CoI、世界纪元和事件出口 | 代替玩家选择、读取房间秘密 |
| 编剧 Agent | 根据事件和卡池生成候选叙事、战报和遭遇 | 直接把候选写成正典 |
| 解说 Agent | 把已落库事件写成人类可读战报 | 添加没有证据的心理事实 |

## 7. 服务器如何形成世界方向

一个服务器就是一个 `worldId`。所有玩家的已结算对局先保留在各自房间，再通过 `world_outbox` 进入世界贡献表。贡献映射只读取公开字段，例如游戏类型、选择方向、胜负、掉落类别、公开的战术标签和匿名化席位趋势。

每个纪元聚合出：`direction`、`anchors`、`truthShards`、`activeRumors`、`evidenceCount`。当某条方向达到门槛，它可以改变可见地点、掉落权重、裁判问题或剧情入口；它不能追溯修改已经结束的对局。

服务器接轨只交换经过签名或哈希校验的公开快照。两个世界先生成 `federation proposal`，检查规则版本、锚点冲突、真相碎片来源和隐私字段，再由天道 Agent 或主控批准。接轨是提案，不是自动合并。

## 8. 山海经元素的使用方式

山海经只作为原创世界的意象与生物档案来源，不直接复刻既有故事。白泽可以成为“证据分类者”，烛阴可以成为昼夜与倒计时的世界符号，讹兽可以成为会放大错误叙述的线索怪物。每次出现都必须绑定地点、游戏事件和可验证掉落，避免装饰性堆名词。

## 9. 正典状态与审查

```text
draft → candidate → witnessed → confirmed
                 ↘ disputed → sealed
```

`draft` 只供创作；`candidate` 可在游戏里作为传闻；`witnessed` 已有事件引用但仍可能被质询；`confirmed` 才能进入公共正史；`disputed` 保留双方证据；`sealed` 只可被满足门槛的玩家或 Agent 看见。

每次晋层、死亡、三局配额结算和世界纪元更新都要生成事件 ID。这样用户可以通过文字战报理解博弈，也能在需要时追溯到真实动作、裁判条款和掉落来源。

## 10. v1 的实现边界

当前版本优先完成确定性世界循环、公开 Gateway、Agent 日报、游戏战报、记忆卡与世界贡献的持久化；模型生成剧情仍然作为带证据引用的候选层。区块链、跨服务器共识和自动化编剧审查保持为后续适配层，不把尚未运行的部分描述为已上线能力。
